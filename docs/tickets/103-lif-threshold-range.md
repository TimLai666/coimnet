## Root 決策 2026-10-15

先驗證 `theta_min = -2^1023`、`theta_max = 2^1023`、`theta_raw = 0`。宣告公式的閾值為 0、對 raw 的斜率為 2^1022，均可表示；直接先算跨度會溢位。不得把合法有限範圍改判非法來讓測試通過。若確認缺陷，正常範圍保持既有運算順序與模型格式，只有不可表示的中間跨度採等價計算。所有產生相同變換的公開路徑都需驗證，真正不可表示的下游數值仍須拒絕且不提交狀態。

這是數值邊界稽核，不證明既有手寫模型受影響，也不取代 LIF 長期訓練品質。完整零 bug 目標保持，先處理確認缺陷，再接續長期品質量測。
