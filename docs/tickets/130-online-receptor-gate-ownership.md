## Root 決策｜2026-10-16

ticket129 的845份正式來源在完整工程期間保持不變。Root 只在專案暫存中以公開 API 建立一般數值的兩節點連線、受體脈衝與局部可塑性，再執行線上作答／回饋／更新。

一般與競態各16個控制逐位相同。gradient、plastic、mixed、evaluate 四種政策都被建構入口接受；受體閘門與化學脈衝同時開啟時，尚未收到回饋的 `Act` 已把快速記憶從0改成0.3052627141695012。關閉受體或脈衝的12個控制沒有這個變化。plastic／mixed 的正回饋另會在 `AdvanceGated` 因重複閘門宣告而失敗，即使化學來源沒有脈衝也會發生。

另把讀出節點改接該突觸的接收端後，一般／競態各16個控制再次一致。評估模式的第三列輸出由對照的0.4734979569911957變為0.5173221230506897，發生在任何回饋之前，證明不是只有不會影響讀出的內部數值改變，見[輸出驗證](../../evidence/MOD-06/consolidation-norm-20261016/next-output-verification.json)。這不是實際任務準確率量測。

嚴重度P1。這是正常數值下違反線上推論、回饋與更新分離的已確認缺陷，會污染 `OnlinePolicy.Evaluate` 的快速記憶。LRN-06回到specified。本票沒有把這項結果延伸成其他適應性評估入口也有相同缺陷，混合更新既有的部分成功契約亦不是另一個原子性缺陷。

根因在 `learning/online.go:267` 的作答呼叫沿用一般持續推論，`learning/individual.go:784-793` 會以受體覆寫零閘門。回饋則在 `learning/online.go:422-434` 再提供明確reward gate，與受體宣告衝突。單在建構時拒絕plastic政策並不能修正gradient／evaluate作答的提前學習，也會移除原本應能組合的化學機制。

修正方向沿用 ticket23 的既有線上契約：`Act` 關閉新可塑性寫入但保留神經、化學與參與紀錄的正常推進；`Update` 的局部學習由reward mapper給定的閘門控制。以私有的單次操作路徑明確指定閘門來源，不改模型宣告與保存欄位，不持久改寫受體、不漏掉化學時間窗，不污染後續原生推論。一般 `Advance` 的受體學習及公開 `AdvanceGated` 的雙重閘門拒絕保持。凍結旗標、取消與失敗原狀另設控制。正式實作前仍須固定私有簽名與所有消費端。

`TrainEpisode` 的獨立zero-state episode契約已在實作與文件明示，本次沒有證據把它不使用持續fast／slow視為缺陷，不改該機制。
