**Blocked by:** 無

## Root 決策｜2026-10-10：共用契約與驗收

必要來源與結果保留。外部資料以無覆寫搬移移入專案已忽略的 data／runs，搬移前後比對 SHA-256。歷史報告、模型及下載回條中的路徑視為當時紀錄，範例命令使用新路徑。目標存在、內容改變或讀取失敗時停止該項操作。未知用途先保留，不當作暫存刪除。

- [x] 讀取與盤點來源內容，保存逐檔指紋、分類與目前使用路徑的相依。
- [x] 搬移外部 TSK-11 資料及執行結果至 data／runs，無覆寫且指紋一致。
- [x] 範例路徑與輸出限制相容於專案內已忽略資料夾，歷史證據不重寫。
- [x] 僅清除已證明可重建或已保存的暫存，必要原件及結果保持。
- [ ] 驗證忽略、活流程、最後盤點、Root 審查與提交推送及遠端核對完成。
