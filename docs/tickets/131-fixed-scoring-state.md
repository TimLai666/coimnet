## Root 決策｜2026-10-16

主規格 7.2 要求固定評估的快速狀態保持或重設後保持。原評分呼叫一般持續推進，沒有受體時仍會衰退快速權重並更新參與紀錄，開啟受體時還會新增學習變化。基礎參數不變的檢查無法發現這項污染。

三種核心、受體開關及快速重設開關的公開案例都重現。正常連續核心中，既有快速權重由 0.25 變成 0.03125，開啟受體時變成 1.0377794296456702，輸出亦與既有凍結契約不同。嚴重度 P1，LRN-10 需重新驗收，不能沿用先前 passed 宣稱。
