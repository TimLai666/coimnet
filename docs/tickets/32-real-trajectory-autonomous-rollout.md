# 32 — 使用者可以在真實軌跡的起始條件下評估模型自主行走

Epic：TSK-11 真實任務資料

User Story：使用者可以載入既有真實軌跡訓練快照，讓模型產生位置與後續動作，並將虛擬獎勵區命中率與單步預測分開查看。

Blocked by：ticket 29 的真實軌跡匯入、訓練與新程序推論已完成。

Status：verified_pending_delivery（2026-10-02）。本票只驗收工程模擬，不自行把 TSK-11 整項標為 passed。

## Root 決策與資料流（2026-10-02）

沿用 Titova 作者儲存庫的固定 gzip CSV、既有模型、前處理與試次分割。原始資料、模型與完整執行輸出留在 Git 外。來源 README 已定義直徑 60 cm 圓形場地，以及 `estimated_food_x_cm`／`estimated_food_y_cm` 為搬移後的虛擬獎勵區中心。

```text
校驗過的來源 -> 整試次分割 -> 每試次最早合法起始位置與已觀測位移
凍結快照 + 起始觀察 -> 核心持續狀態 -> 預測位移 -> 工程場地更新位置
                                                ^                |
                                                +-- 新觀察 ------+
虛擬獎勵區中心 ---------------------------> 計分器
```

1. 匯入增加明示的評估 metadata 入口，與原有 `Read` 分開。既有 `Read` 及 `Input` 行為保持不變。目標座標只供計分，不進樣本或模型。僅採 `after_relocation` 的中心，試次內須固定且有限，缺欄位或不一致直接拒絕。
2. 每個試次只用最早一對合法 `after_relocation` 列初始化。合法條件沿用現有時間差與位移上限，不依命中結果挑選起點；沒有合法對的試次列出排除原因。模型後續動作不採用來源位置、時間或位移。
3. 預設 200 個模型決策步，每步輸入的時間差固定 0.1 秒。這是前處理特徵的工程值，不能換算為動物的實際行走時間。來源經時間與距離雙重降採樣，預測位移不是原始速度。
4. 場地半徑 30 cm。位移長度上限沿用 5 cm，超過時縮放並計數；若候選終點出場地，位置不動、已實現位移為零並記碰撞。直線行動穿過半徑 2 cm 的虛擬獎勵區時，第一次命中算成功。2 cm 是本票事前固定的工程判讀半徑，作者原始預印本記錄的區域半徑為 2.8 cm，正式觀察窗為 100 秒（[預印本](https://doi.org/10.1101/2022.07.22.501185)、[PubMed 圖說](https://pubmed.ncbi.nlm.nih.gov/37226998/)）；本票不冒稱重現。
5. 保留 256 列神經重設規則，推論不更新基礎參數或最佳化器。方向延續、零位移、固定 seed 隨機方向都使用相同場地、步數與起點。rewarded／non-rewarded 分開報告，後者只能稱假設區域命中，不能稱回到曾獲獎勵的地方。
6. 新增 `realnav rollout --data PATH --snapshot PATH --out DIR`。保存獨立 schema 的完整有效協定、來源／快照指紋、每試次／每策略結果、排除清單與限制。原 `train`／`infer` 格式與既有模型相容性不變。

## 錯誤、空值與互動的責任

本票統一負責以下驗收，無資料庫或格式遷移。

| 操作 | 錯誤或例外 | 結果與驗證 |
| --- | --- | --- |
| 讀取資料與快照 | hash、欄位、版本、shape、來源或分割不一致 | 沿用既有嚴格拒絕，不產生成功報告 |
| 建立評估起點 | 無合法列對、空／重複試次、非有限目標 | 排除無合法列對；結構錯誤拒絕；全空拒絕 |
| 核心與行動 | NaN／Inf、取消、錯誤形狀、過大位移 | 拒絕非有限值，取消回錯；合法過大動作明示縮放與計數 |
| 場地與計分 | 起始點在目標內、擦邊、穿越目標、邊界碰撞、零速度 | 起始成功單獨記錄，線段交會手算測試，碰撞後歷史使用實現位移 |
| 輸出 | 已存在、來源／repo 重疊、並行搶寫、I/O 失敗 | 沿用既有排他寫入與路徑保護，不覆寫原件 |
| 控制組與隔離 | 試次次序改變、不同策略共享神經狀態、目標污染 | 每試次／策略獨立狀態與隨機流；改目標只影響計分，改未來軌跡不影響動作 |

## 限制與減法審查

這是由真實起始觀察驅動的反事實工程場地，不是新蒐集的閉環動物資料，不驗證果蠅力學、視覺、嗅覺、熱牆或路徑整合機制。現有模型只學下一步觀測位移，沒有重新訓練回巢目標。命中結果可能很差，照實保留。TSK-11 整項仍需依原主規格獨立判斷。

不新增模型工廠、核心算法、訓練策略或大型資料下載。建議簡化為既有模型的單一新評估入口，避免複製匯入、前處理或保存流程。
