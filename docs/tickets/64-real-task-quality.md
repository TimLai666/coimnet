## 使用者可以做到的事

以真實 KMNIST 單字元資料驗證 CoImNet 模型，區分資料、輸入時序、目標設定與框架錯誤。新模式由明示設定選用，既有模型保持原行為。

## 已確認的問題

- 舊設定在 1,000 與 10,000 次更新後，開發測試皆為 10% 正確率，所有圖片輸出同一個字。
- 同樣的 1,000／200 圖片，四個最近鄰對照為 61%。
- 欄位輸入的第一個 hidden 讀出尚未收到圖片，最後欄也沒有後續步讓訊號到達 hidden。對齊讀出及補終止步後，10 筆訓練資料的正確率由 10% 提升到 60%。
- 完整圖片輸入加最後讀出分類的原型可記住 10 筆樣本。1,000 筆訓練的開發測試為 62.5%，這還不是正式品質結果。

命令與原始結果保存於 [品質證據](../../evidence/TSK-11/quality-20261012/)。正式設定見 [protocol.json](../../evidence/TSK-11/quality-20261012/protocol.json)。

## 骨架與錯誤處理

`RecognizerConfig.InputProfile` 選擇空值／`columns` 的舊流程、`aligned-columns` 或 `single-character`。`CharacterWidth` 只供單字元模式使用。

| 輸入與使用流程 | 預期結果／失敗處理 |
| --- | --- |
| aligned-columns | 原始欄位加一列零輸入，讀出略過盲首列，CTC 梯度補回首列零，最後欄能影響答案 |
| single-character | 一列完整圖片加一列零傳遞步，僅最後列以字母表分類，空標籤或多字標籤拒絕 |
| 非法 profile、尺寸、非有限值或容量溢位 | 配置或更新前回錯，模型與輸入維持原樣 |
| 保存、載入與 CLI | profile、尺寸、encoder 容量與實際目標明示，載入不重訓，設定不符拒絕 |
| 舊模式與模型 | 原設定、輸出、參數、最佳化器與恢復行為保持 |
