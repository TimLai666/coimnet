## Root 決策｜2026-10-15

主規格 10.3 的 `pre_activity*post_activity` 沒有時間索引。ticket 18 後加的 `pre(t)*post(t+1)` 誤稱為原式，也沒有定義取樣時點。其手算表、共用套件與兩個執行入口一致使用核心推進後同一列的活動。目前沒有足以證明演算法錯誤的規格或執行證據。

文件沿用不帶活動索引的參考式，明列現有取樣時點為工程假設。LIF 是來源當列突觸跡乘上目標當列事件；連續核心是兩端當列輸出。局部狀態更新後的有效權重於下一列使用。這次只修正文件，不改活動取樣、學習算式、模型參數或保存格式，也不選定另一種生物規則。

兩列 LIF 的區分案例中，來源前一列突觸跡為 1，當列為 `exp(-1)`，目標當列事件為 1。既有行為的 eligibility 是 `exp(-1)`；改用步驟前來源則是 1。這個差別確實會改變學習，不能當成單純改符號而修改正常模型。時點何者符合生理量測或改善任務品質，不在本票結論內。
