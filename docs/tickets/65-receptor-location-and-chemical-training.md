# 65｜受體位置與一般化學訓練

狀態：in_progress。前置：21、22、25 的既有 CPU 機制。

## 使用者可以做到的事

接入有來源的受體實測分布或細胞內位置，並讓一般訓練使用化學狀態。資料精度、工程反應係數與訓練路徑分開保存和驗證。

## Root 決策（2026-10-12）

- 沿用區域濃度與受體宣告，新增可選 `Receptor.Location`。位置指名化學區域、細胞內部位、原研究位置、量測方式、證據與映射版本。缺省保持舊 JSON 與行為。受體位於不同化學區域時，讀當地濃度，不再使用神經元的單一區域。後續效果仍由純量神經元整合，不能稱為多區室膜模型。
- 接入來源須分開「實驗在哪個細胞類型／部位看到受體」與「如何對應本模型的節點／區域」。沒有個別 MaleCNS ID 的研究只能作明示類型推論，不能冒稱每個節點都量測過。mRNA 不當成蛋白定位或反應強度。
- 一般訓練必須使用化學釋放、濃度、受體反應及核心的同一條時間路徑。神經活動驅動釋放造成的回授也需要計入反向，不能凍結整條化學序列後冒稱完整梯度。答案只進損失。
- 沿用獨立訓練 episode 的神經生命週期，明示化學狀態的起點與成功提交方式。取消、非法輸入或數值錯誤不得留下半次參數、最佳化器或化學狀態更新。保存、載入及分段重算不能重複釋放或更新。

## 骨架、錯誤與驗收流程

| 使用流程 | 預期行為與失敗處理 | 驗證 |
| --- | --- | --- |
| 帶來源的位置 → 受體 → 當地濃度 → 效果 | 每筆位置區域有界、部位已知、來源及映射非空。位置未知保持未知；非法位置在運算前拒絕 | 不同區域的手算反應、未知反應分離、舊 wire 逐位相容、深複製 |
| 真實來源 → 明示節點映射 → 訓練／干預範例 | 保存來源、授權、版本、指紋、觀察與推論的界線；不捏造密度或反應係數 | 實際來源讀回、相同條件位置／化學開關對照 |
| 一般訓練 → 化學狀態 → 神經訊號 → 損失 → 更新 | 前向與反向使用相同化學時間序列；延遲回饋只在可取得時間進入 | 平滑全路徑有限差分、脈衝宣告替代公式、核心／encoder 更新 |
| 中途存檔 → 新程序接續 | 位置、化學、最佳化器、必要來源狀態一致；損壞或缺欄拒絕 | 不中斷與新程序比對、失敗原子性、並行隔離 |
| 分段重算與關閉機制 | 不重複來源副作用；關閉與原始參考一致，不靜默忽略未支援組合 | 參考梯度／更新相等、能力界線、完整一般及 race |
