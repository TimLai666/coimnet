# 35 — 研究者可以確認凍結模型是否使用搬移前刺激

Epic：真實任務與能力歸因（TSK-11）。
User Story：同一模型只改過去刺激，研究者可以核對後段預測與自主行走是否改變。
Blocked by：34，已完成。
Status：verified，4／5 已驗證，交付待核對。

## 固定方法

沿用 ticket 34 的原件、九組模型、三個 seed、訓練前後快照與原 13 test，不重新訓練或調參。來源與 bundle 保留在 Git 外。比較原輸入與清除刺激輸入，每個比較都從零狀態開始。

清除範圍是第一個 `relocation` 來源列之前的模型可見刺激欄。先套用 delivered／no_stimulus／shuffled_stimulus 的既有轉換，再只把這段的第六欄設為零。其他五欄、時鐘、標籤、完整歷史及搬移開始後的刺激輸入逐位不變。打亂組的後段排程仍依原始刺激建立，避免把當下刺激改變誤認為記憶差異。此操作測模型可見刺激歷史，不是改寫活體實驗。

記錄全部搬移後合法遮罩列的原／清除 MSE、輸出差異的最大 Euclidean 距離（cm）、非零及大於 `1e-6 cm` 的列數。門檻只是事前固定的工程解析尺度，不是生物或導航成功門檻。另記最早差異與完整預測指紋，不把小於尺度的值抹成零。

自主評估沿用原評分器、200 決策與起始觀察。只清除重播前綴內、搬移開始之前的刺激，原本的 raw stimulus 區塊與後續因果轉換保留。保存兩側全部試次的命中、距離、碰撞、完整 trace 指紋、最大行動差異與最大位置分離。後續位置可以因模型動作而分岔，觀測式預測與自主評估分開判讀。

未訓練零 readout、無刺激模型及無 delivered 的試次保留為零差異檢查。輸出改變只能證明此模型對歷史輸入敏感，不能單獨證明記憶有用、導航成功或果蠅機制。既有測試集不是全新未見資料。需求仍為 89／91，TSK-11、OPS-05 不提升狀態。

## 流程與失敗責任

`counterfactual --input --model --out-dir` → 同次來源校驗與 phase 邊界 → bundle／分割驗證 → 原／清除配對 → 排他發布 report。全部責任由本 ticket 驗收。

| 入口或情境 | 必要行為與驗證 |
| --- | --- |
| 正常來源與模型 | 九組 × 訓練前後 × 全部 13 test，零排除，位置與後段刺激指紋一致 |
| 缺少搬移、空／非法邊界、錯來源／模型 | 明確回錯，不建立輸出。沿用嚴格 JSON 與完整來源校驗 |
| 零刺激／零 readout | 配對輸出逐位相同，保留零值，不假造改善 |
| 取消、並行及既有輸出 | 不覆寫、僅完整發布、取消沒有部分成果。沿用排他寫入 |
| 凍結與舊流程 | 參數／optimizer／原始資料不變，原 rollout 逐位相同 |

## 實作骨架與驗收

`counterfactual.go` 的 `counterfactualInputs(trial, cutoff, control, seed)` 回傳全長原／清除模型輸入與改變列數。只清除 `[0, cutoff)` 刺激，錯邊界／輸入回錯。`compareMemoryTrial(ctx, snapshot, trial, cutoff, target, control, seed)` 回傳配對的預測與行走差異，不能更新參數。`buildMemoryCounterfactualReport` 保留所有組別與試次，錯誤回空報告。既有行走內部新增可選清除界線，舊入口界線為零。

- [x] 輸入配對：只改搬移前刺激，時鐘、位置、後段刺激完全一致。非法與零值覆蓋。
- [x] 數值與因果：早期刺激確實可影響後段。零 readout／無刺激無差異。打亂後段不變，來源與模型凍結。
- [x] 完整命令：help、正常及錯誤、取消／不覆寫。原命令相容。
- [x] 真實評估：全部配對保留，兩個新程序位元組相同，原組與 ticket 34 相符，輸入指紋不變。
- [ ] 交付：完整格式／build／一般／race／vet／相依性、獨立審查、文件與證據、提交推送及遠端核對。

減法審查：共用原模型、核心及行走評分，不新增模型組、reward、RL 或生物假設。差異先按實際大小判讀，不追加事後挑選的門檻。

## 實際結果

九組模型的訓練前後共 234 配對，兩個新程序逐位元組相同。三個 seed 的已訓練 delivered 與 shuffled 組各有八個 rewarded 試次的後段輸出改變，no_stimulus、未訓練及五個 non-rewarded 試次差異精確為零。原／清除組皆 0／13。清除刺激對 MSE 的效應在 seed 20261004 為負、其他兩個為正，沒有一致記憶收益。[逐組摘要](../../evidence/TSK-11/stimulus-counterfactual-20261003/summary.json)、[配對報告](../../evidence/TSK-11/stimulus-counterfactual-20261003/report.json)。
