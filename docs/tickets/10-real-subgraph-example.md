# 10 — 研究者可以重現真實子圖選取並接上訓練核心

Epic：真實接線資料整合

User Story：研究者可以保存真實子圖的選取條件與來源指紋，讀回後執行明示為人工任務的短訓練範例。

Blocked by：08、09、04

Status：verified_scoped

## 交付與流程

明示選取條件的範例 manifest → 既有 `data import --out-store` → 新圖檔 → 範例讀取並核對選取 hash、規模 → 依 canonical 邊順序建立現有連續核心 → 人工脈衝任務的短訓練 → JSON 報告。

沿用 manifest 的單欄位相等選取，不新增查詢語言或修改原圖。範例選取 `annotations.class == "ALIN"`，所有該類別的節點均納入，不為達到特定節點數再裁切。這是工程整合範例，不宣稱完整神經迴路或真實行為成績。訓練程式位於 `examples/`，不輸出或提交模型參數。

## 決策

- 子圖由三份原件重新建構，保存 class 選取及輸入 hash。它與原本 status=Traced 的完整宣告視圖是兩份獨立衍生物，不把兩者的條件混在一起。
- 範例只消費 `connectome`、`dynamics` 與 `learning` 現有公開 API，不新增框架抽象或變更圖檔格式。
- 邊權重初始化採非負原始 weight 的每個目標節點加總正規化，再乘 0.1。這是明示的數值假設，不從傳導物質推斷符號。延遲為零，DT=0.1、tau=1、tanh。只訓練核心邊權重，固定輸入、讀出與其他神經參數。
- 範例使用固定四步人工正負脈衝與兩個目標值，報告前後損失、權重變動與指紋。短訓練驗證整合，DAT-07 的驗收依原文限於真實子圖範圍與來源追溯，不要求生物行為或保留資料達標。
- 範例最多 2,000 節點、100,000 條邊與 1,000 次更新；超限拒絕，不能自動裁圖。這是範例執行範圍，完整框架容量估算另依 OPS-06。

## 錯誤、邊界與驗收

| 情況／操作 | 預期行為 | 驗證入口 |
| --- | --- | --- |
| 有效真實子圖 | 保存條件與來源，輸出 profile、節點／邊數、ID 對照、來源報告、圖檔與參數指紋 | 真實 CLI 範例及獨立選取稽核 |
| 檔案、選取 hash、JSON 或輸出失敗 | 明確返回錯誤，不輸出成功報告 | 範例命令測試 |
| 空圖、零邊、超限或更新數非法 | 訓練前拒絕，原圖不變 | 零邊／更新數 fixture；節點與邊數上下限程式審查 |
| null／負權重或重複 pair | 此範例拒絕，不推測生物符號或重複加總語意 | 例子人工 fixture |
| 取消、中斷、重複執行 | 不覆寫圖檔、不寫模型；同一輸入重跑結果一致 | 取消測試、兩次真實範例輸出比較 |
| 神經 ID 與運算邊 | 保留 uint64 十進位 ID、canonical 索引與所有選入邊，權重更新不改圖 | 公開 Build/Save/Load 到訓練的整合測試 |
| 學習更新 | 非零有限梯度與核心權重變動，固定參數不變 | 人工測試及真實短訓練 |

- [x] 真實選取與獨立稽核相等，三份原件及既有完整圖前後指紋一致。
- [x] Mac／Ubuntu 執行同一份來源與真實子圖，保存日誌、命令、環境、時間及記憶體。
- [x] 原始 DAT-07 驗收有完整證據後才更新需求狀態。
