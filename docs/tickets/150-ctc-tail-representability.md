## Root 決策（2026-10-18）：根因與驗證骨架

單一時間點的 `[-40,0]` 配 target `[1]`，及 `[0,-40]` 配空 target，都把約 `4.248354255291589e-18` 的正誤差與正確類別導數回傳為零。兩個時間點都為 `[-40,0]` 配 target `[1]` 時，正誤差與每列正負導數約為 `1.804851387845415e-35`，實際誤差及導數全零。四個問題案例的一般／競態輸出相同，兩個等分正常控制通過，見 [Root 核對](../../evidence/TSK-02/ctc-tail-audit-20261018/root-review.json)。

最早遺失在正規化先加 1 與極小指數項再取 log，路徑合併的 lse2 有相同寫法，導數又以接近 1 的兩個數相減。不能只加單一時間點特例。後續先固定一與多個時間點、空／重複／不同 target、排列、真正下溢、非法輸入及既有數值拒絕的獨立參考，再寫原版失敗回歸。保留正常模型、不可對齊政策、公開介面與保存格式；尚未選定新演算法或正式採用精度補充分支。

`1e-8` 只檢查條件機率總和，既有近零有限差分跳過條件不能證明本次數值正確。此票須明示 loss 與逐項導數的驗收門檻及近零值規則，不以放寬舊測試處理。模型 CER／WER 或長期品質影響目前未知。
