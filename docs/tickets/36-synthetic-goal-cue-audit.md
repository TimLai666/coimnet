# 36 — 研究者可以判斷小型策略是否依目標提示自主抵達

Epic：環境學習與導航驗收（LRN-09，TSK-11 的前置方法檢查）。
User Story：研究者可以區分平均回報改善、抵達目標與使用起始提示三種結果。
Blocked by：26 的既有 PPO 範例，已完成。
Status：in_progress，4／5 已驗證。

## 固定方法

沿用 DefaultPPOExperimentConfig：長度 7、20 步、每步 −0.01、目標 +1，seed 1／2／3，各 200 更新、8 hidden、學習率 0.01。收集器、PPO、模型拓撲與模仿模型不變。新證據在既有 experiment 人工範例的環境變數測試入口產生，不增加公開 API、CLI 或模型產品。

每個 seed 都建立訓練前與訓練後策略。以既有 1000～1039 環境種子評估，保存全部回合及左右目標分層。環境只有兩種目標情境，40 回合不能當作 40 種獨立導航問題。訓練後完整快照摘要須等於既有 RunPPO，同樣預算重新產生的結果，確認沒有暗改訓練。

評估包含 sampled、greedy、random。sampled 每回合的 PCG 第一種子為環境種子，第二種子固定 0x1004，訓練前後與提示對照共用每回合的亂數來源。greedy 在最高分平手時選最小動作索引。random 不讀模型。只在第一筆觀察清除 cue 或反轉其正負號，環境中的實際目標不改，之後只有自身行動造成的觀察差異。每回合從個體副本的零神經狀態開始，原參數、神經狀態與最佳化器保持不變。目標座標只供計分。

事前工程門檻：每個 seed 的 sampled 左右抵達率各 ≥0.8，總抵達率較訓練前及同環境 random 各增加 ≥0.15，反轉提示使總抵達率下降 ≥0.2，greedy 左右均抵達。三個 seed 全部滿足才記 goal_cue_gate=true。此門檻是本人工任務的工作判準，不是統計顯著性或生物門檻。門檻失敗仍須保存完整結果，不改參數追求通過；切片完成與學習通過分開。

## 流程與錯誤處理

環境變數入口 → 固定設定 → 既有收集／更新 → 個體副本評估 → 每回合 trace／分層摘要／判準 → 不覆寫 JSON。所有邏輯只存在測試範例。nil context、nil 個體、未知行動／提示模式、sampled 無 RNG、非法環境或取消返回錯誤；測試提供手算提示策略與原 collector 一致性對照。空評估集合不能產生成功判準；輸出檔已存在時拒絕寫入。

## 驗收

- [x] 固定設定與 200 次更新，三個 seed 最終摘要等於既有 RunPPO。
- [x] 先失敗再通過：手算左右提示策略、清除／反轉提示、sampled 原 collector trace 一致、非法入口／取消、個體不變。
- [x] 保留訓練前後、random、兩種選擇方式與提示對照的全回合及左右摘要，照固定門檻判讀。
- [x] 兩個新程序報告位元組一致，完整格式／build／一般／race／vet／依賴檢查與獨立審查完成。
- [ ] 同步文件、需求證據與進度，驗證階段提交推送並核對遠端。

## 減法審查

沿用既有 PPO 與人工走廊，省去新環境、新演算法和延長訓練。真實軌跡、全圖與 GPU 不在此切片。平均回報已驗收，不再以同一 aggregate gate 宣稱新導航成果。

## 實際結果

[分層摘要](../../evidence/LRN-09/goal-cue-audit-20261003/summary.json) 與 [完整回合](../../evidence/LRN-09/goal-cue-audit-20261003/report.json.gz) 保存 39 組、1,560 回合。訓練後 sampled 抵達率為 50%、97.5%、67.5%，只有 seed 2 通過工作判準，整體 goal_cue_gate=false。seed 2 未訓練 greedy 已為 100%；訓練後 seed 2／3 清除提示的 greedy 仍為 100%。20 步允許先走錯端再走到另一端，至少只需 9 步，因此本設定不能證明提示記憶是成功必要條件。

固定方法保持不變。下一個方法應另設較短時限，排除兩端搜尋，事前鎖定訓練與評估方法後再執行。這不是本票的事後調參。
