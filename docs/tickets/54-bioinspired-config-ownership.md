# Ticket 54：研究者可以保留生物啟發協定執行當時的設定

**Epic:** 訓練框架的可保存設定
**User Story:** 研究者可以修改下一次實驗設定，先前報告的設定、雜湊與結果保持一致
**Blocked by:** 無；52、53 是已完成的來源基準
**Status:** in_progress

## Root 決策｜2026-10-10：問題與共用契約

兩種生物啟發協定的報告直接保存呼叫端的設定。共用入口在原有驗證後、雜湊與執行前複製種子、脈衝步、來源登錄與定量證據資料。每次執行各自持有設定，保留 nil、非 nil 空切片、欄位順序與原有錯誤。數值與模型保持。

| 條件／操作 | 預期結果／處理 | 本票驗收 |
| --- | --- | --- |
| 回傳後修改呼叫端設定 | 整份舊報告與雜湊保持 | 兩協定七組欄位回歸 |
| 修改報告與追加預留容量 | 呼叫端及第二份報告保持 | 反向與報告間隔離 |
| nil、非 nil 空脈衝與可選證據 | 值與 JSON 表示保持 | 空值、雜湊控制 |
| 非法設定、nil context、取消、時機超出回合 | 原錯誤與零／部分報告保持 | 既有錯誤控制與部分報告隔離 |
| 合法 SDK | 完整報告與修正前逐位元組相同 | 修正前及雙程序對照 |
