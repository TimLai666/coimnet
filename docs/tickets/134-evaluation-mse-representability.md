## Root 決策｜2026-10-16

Root 以公開 RunAdaptiveEvaluation 重現 P2 缺陷。單節點、兩維零輸出的合法固定評估，目標皆為有限的1e154，最終平均平方誤差應為1e308，實際卻是+Inf，json.Marshal報告失敗。一般／競態的兩列公開結果逐位相同，0.5目標的正常控制為0.25且可正常編碼。以math/big.Rat對精確float64目標計算獨立參考，見[驗證](../../evidence/LRN-10/feedback-permission-20261016/next-mse-verification.json)。

根因是experiment/adaptive_run.go的itemMSE先加總平方，再除以維度。中間和溢位，但最終平均仍可表示。這個共用函式供固定／適應後評分及允許的適應分數使用。此發現限於極端有限值，沒有證明一般OCR資料的辨識率受影響。
