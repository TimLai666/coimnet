## 01｜專案定位與交接原則

### 1.1 要解決的問題

生物神經接線圖告訴我們神經元如何相連，卻不直接等於能執行任務的 AI 模型。CoImNet 要補上可替換的神經運作模型、輸入與輸出轉換、學習方法、時間狀態、化學調節，以及能追查成果來源的實驗系統。它既不是只顯示大腦的瀏覽器，也不是把外部大型模型的結果轉送出去的包裝工具。

CoImNet 的研究對象是「由真實接線約束的可學習計算系統」。固定接線、連續神經元、脈衝神經元、人工調節器各自是可比較的實驗條件，不能僅憑專案名稱宣稱形成新的學術分類或優於既有方法。

### 1.2 完整範圍

最終儲存庫必須包含：真實接線資料匯入與版本管理、可替換神經動態、自訂多模態訊號、離線與運行中學習、局部可塑性、獎懲與教師學習、化學／荷爾蒙調節、完整狀態保存、五類任務的訓練與評估、共用核心的多模態實驗、對照組、效能量測、SDK、CLI、自動測試與使用文件。

五類任務為：**OCR、語音轉文字、語言生成、文字轉影音、空間與導航**。文字轉影音需涵蓋影像、音訊、影片及同步輸出的資料契約與可執行參考流程。不得把語音轉文字換成聲音分類，或把影片生成換成呼叫外部生成服務後宣稱核心學會生成。

### 1.3 「最完整」的可驗收定義

完整不是無限加入功能，而是本文件所有必要需求都有實作、文件、測試、失敗處理及證據。允許分批建置，但不能只完成第一批就稱為本企劃完成。

必須分別報告三種結果：

| 層級 | 成立條件 | 不代表什麼 |
|---|---|---|
| 軟體完整性 | 指定功能可執行，數值與資料契約通過測試，所有必要工作都有證據。 | 不代表任務精度已達商用品質。 |
| 學習與任務能力 | 指定資料、設定與測試集上的學習曲線、成績及對照結果可重現。 | 不代表所有資料、語言或解析度都能泛化。 |
| 生物對應 | 特定生物實驗、物種、細胞與干預結果被正確重現。 | 不代表整顆數位大腦等同活體，或有意識。 |

真實全腦、多模態與長期學習是需要量測的研究目標。不能預先保證它們的品質，也不能因結果不如預期而刪除相應功能或省略負面結果。若全腦或 GPU 測試受硬體限制，必須標示受阻，不能拿小型資料的成功替代。

### 1.4 本文件的權威順序

已確認的使用者決策優先，其次是本文必要需求，再其次是建議實作方式。參考方程式與預設數值屬工程起點，並非完整果蠅生理定律。Agent 可調整套件拆分、內部架構、演算法實作及工作順序，但不得改變外部行為、縮減範圍、隱藏資料替換或擅自增加付費／發布授權。

## 03｜研究基礎與不可沿用的推論

### 3.1 已核對的依據

| 來源 | 可借用的部分 | 使用限制 |
|---|---|---|
| MaleCNS 官方首頁與下載頁 [S01][S02] | 主資料來源、版本、神經元註記、傳導物質預測及完整分段連線檔。 | 分段完整圖不自動等於已篩選的神經元圖。實際欄位與數量要由匯入報告確認。 |
| Lappalainen 等，Nature 2024 [S06] | 接線約束的連續動態、任務訓練、共享參數及限制讀出端資訊的實驗設計。 | 果蠅視覺系統的結果，不是五類任務或 MaleCNS 全系統的保證。 |
| FlyGM，arXiv 預印本 [S07] | 將接線作為有向訊息傳遞圖，以及重新接線與一般網路對照。 | 計算圖節點向量不等於測得膜電位。不得混稱資料集或預印本狀態。 |
| 脈衝網路與替代梯度研究 [S08][S09] | 適應性閾值與跨離散放電的訓練方法。 | 替代梯度是工程近似，不是硬閾值函數的真實導數。 |
| Backpropamine [S10] | 穩定權重與可變連線狀態、調節訊號及近期連線參與紀錄。 | 原論文的 episodic 重設不等於永久持續學習已獲保證。 |
| FiLM [S11]、ANML [S12]、HyperNetworks [S13] | 當下活動調節、選擇性學習與小網路產生部分參數。 | 皆不是果蠅荷爾蒙方程式。外加網路的能力必須列入對照。 |
| Ishimoto 等，PNAS 2009 [S14] | 成年果蠅的 20E 與長期求偶記憶，給藥時機影響結果。 | 不能簡化成濃度越高記憶越好。本文不指定全腦定量參數。 |
| Krashes 等，Cell 2009 [S15] | NPF／多巴胺迴路使內在狀態影響記憶表現。 | 暫時不表現記憶不一定是遺忘。 |
| Chemoconnectomics，Neuron 2019 [S16] | 傳訊物質、神經胜肽、受體與細胞對應的研究框架。 | 不是 MaleCNS 每顆神經元的完整受體敏感度表。 |
| 內在需求驅動的獎勵模型 [S17] | 生理狀態與獎勵價值的分離及聯結。 | 適合有內在資源的環境，不應硬塞到每個 OCR 任務。 |
| 蒸餾、CTC、PPO 原始研究 [S18][S19][S20] | 分別支援教師學習、無逐時對齊的序列辨識，以及以行動回饋學習。 | 需實作適用的數值方法，不是加上名稱即完成。 |

### 3.2 必須寫進 README 的科學界線

接線圖不是已訓練好的全能模型。神經傳導物質預測不等於已量測的突觸作用正負；作用還可能依受體與情境不同。未知受體不是「沒有受體」。數千萬個突觸接點也不等於同樣數量的獨立神經元配對或可訓練參數。[S02][S16]

獎勵、懲罰、損失函數、神經調節物質、內分泌荷爾蒙是不同概念。可在模型中建立映射，但不能互相改名後宣稱生物合理。[S10][S14][S15]

統一訊號容器不會自動建立共同語意。小型或低解析度任務成功，不足以證明一般語言或自然影音能力。固定編碼器也可能已具有強能力，因此固定編碼器不等於能力歸因已完成。

### 3.3 證據登錄

每種機制必須記錄 `mechanism_id`、版本、來源、物種、腦區／細胞類型、量測或推估方法、適用範圍、未支持事項、參數單位、未知欄位及對照測試。證據分為 `measured`、`predicted`、`cell_type_inferred`、`general_neuroscience`、`engineering_hypothesis`、`unverified`，不得只用一個「high confidence」取代來源與限制。

模型的工程預設不因寫進程式就升格為生物定律。研究更新只能產生新版本的設定，不能靜默改掉舊實驗。

## 04｜技術環境與 Insyra 的整合要求

### 4.1 已查核的基準

本企劃核對 Insyra 的提交為：

```text
1f1cdb949c51a10be104965cf4cf30f8f0aaa648
```

該提交的根 `go.mod` 宣告 `go 1.25.12`。[S03] 接手時先取得這個提交進行相容性測試；若改用更新版本，記錄原因、實際 module 版本與測試差異。不得在交付中留下未固定的 `@latest` 依賴。

已核對的 `nn` 文件包含張量、部分 ONNX／SafeTensors 能力、訓練 tape、常見損失及最佳化器。`Sequential.Fit` 不負責 CoImNet 所需的資料集、checkpoint 或完整持續學習狀態；文件亦未宣稱完整裝置端訓練。[S04]

`nn/autodiff.go` 中的操作紀錄與參數欄位有非公開成員。不能假設外部套件可直接註冊任意稀疏操作，或把外部計算結果塞回 tape 就會自動接上梯度。[S05] 本企劃做的是原始碼與文件查核，沒有執行 Insyra 或 CoImNet 的編譯與效能測試。

### 4.2 實作方式的選擇界線

Insyra 應實際用在資料處理、張量邊界、已支援的數值操作、可用的編碼／讀出模型及結果統計。高頻神經狀態不可逐步經過會複製資料的 DataTable 存取。

缺少的稀疏運算與跨時間訓練必須真正補齊。Agent 可選擇在 CoImNet 內建立窄範圍的稀疏前向／反向計算模組，或利用已存在且已驗證的 Insyra 擴充點整合。不得用反射或 `unsafe` 篡改非公開欄位，不得將核心 detach 後只訓練外圍，再宣稱完整端到端訓練。

若選本地反向計算，必須明確定義梯度如何跨過編碼器、核心及讀出器的邊界，並提供完整路徑的測試；它仍需使用指定 Insyra 基礎，不能暗中換成另一套主要框架。若最好的方案需要改 Insyra，先提交必要變更說明與最小測試，取得上游變更授權後才動上游。其他不依賴該變更的工作繼續。

### 4.3 平台與依賴

CPU 目標為 Linux amd64、Windows amd64、macOS arm64。不可把只做交叉編譯當成在三平台執行測試。無相應執行環境的平台應標示未驗證。

核心運行不依賴 Python。Python／PyTorch 可作開發期間的數值比較工具，但一般安裝、基本例子、CPU 訓練與推論不能要求它。大型外部模型與影片封裝器可作選用整合，必須在 `doctor` 與能力清單中顯示依賴及版本。

官方 MaleCNS 使用 Feather 檔案。需識別 Feather 版本並以適合的 Arrow 讀取方式處理，不得當成 CSV 或直接假設 Insyra 已有這個 API。Feather v2 與 Arrow IPC 的對應可參考官方文件，Go 的 IPC 讀取介面可作實作候選。[S21][S22]

### 4.4 能力偵測

每個運算後端宣告能否處理：連續前向、脈衝前向、稀疏反向、可變權重、教師損失、裝置狀態保存及決定性模式。設定要求未支援的組合時，執行前就返回具體錯誤。CPU 回退必須明示，不能在 GPU 失敗後悄悄重複執行半次學習更新。

## 05｜資料生命週期與真實接線匯入

### 5.1 主要資料與重現資料

主要 adapter 為 MaleCNS v1.0。官方頁面列有以下三項最小來源：[S01][S02]

| 官方檔名 | 用途 |
|---|---|
| `connectome-weights-male-cns-v1.0-minconf-0.5.feather` | 分段至分段的完整連線圖。 |
| `body-annotations-male-cns-v1.0-minconf-0.5.feather` | 人工整理的細胞種類、類型、側別等註記。 |
| `body-neurotransmitters-male-cns-v1.0.feather` | 每個神經元的傳導物質預測。 |

細部突觸位置、骨架與受體資料不是啟動基本全腦運算的必要下載項目；只有所選機制需要時才取得。每種 adapter 要鎖定實際取得的版本、欄位映射與篩選規則。

FlyWire adapter 用於獨立實驗或論文重現。資料集、物種性別、版本及 ID 空間必須分開。沒有正式映射證據時，禁止依 ID、名稱或相似類型直接拼接 MaleCNS 與 FlyWire。

### 5.2 原始檔與標準化資料

原始檔只讀保存。標準化結果是另一份可重建的衍生物，包含來源清單、轉換器版本及輸入雜湊。先以官方欄位建立實際 adapter 的欄位表，再轉換成本文的標準欄位；本文欄位名稱不是宣稱官方檔案原本就這樣命名。

外部 neuron ID 以 `uint64` 或無損十進位字串保留；JSON 使用字串，避免經過會失去大整數精度的程式。內部可建立連續索引，但必須保存可逆對照表。索引寬度由數量檢查決定，不得無聲截成 32 位元。

### 5.3 選取範圍與統計

至少提供 `raw_segments` 與 `annotated_neurons` 兩種具名視圖。報告包含：原始分段數、選入神經元數、排除原因、無對應註記的端點數、神經元配對數、原始接點加總、未知傳導物質比例、未知受體比例、孤立節點、自我連線與重複邊。

不得為了符合文宣中的神經元數而調整篩選條件。`male-full` 指依宣告規則選取的完整神經元視圖，不得稱為已模擬每個身體組織或所有化學傳遞。

相同配對的多筆紀錄只有在來源確定是可加總的區域分割時才聚合。若同時含總數與各區域數，不能再次相加。未知的重複語意要拒絕匯入並指出欄位，不能任意去重。

### 5.4 下載與完整性

下載器支援取消、有限次重試、斷點續傳、暫存檔、磁碟空間檢查及原子更名。伺服器忽略 Range、ETag 改變或內容長度不符時，不可續接舊檔。不得執行下載檔案中的指令。

雜湊區分 `upstream_verified` 與 `locally_recorded`。自行算出 SHA-256 只能證明之後是否改變，不能假裝已和官方校驗值比對。官方沒有校驗值時，記錄來源網址、時間、大小、回應標頭與本地雜湊。

### 5.5 必備標準欄位

`DatasetManifest` 必須含 schema 版本、資料集識別、來源版本、檔案角色與校驗、授權來源、取得時間、欄位映射、篩選條件、座標單位與轉換歷史。

`NeuronRecord` 必須含資料集命名空間、外部 ID、內部索引、類型、區域、來源與品質註記。未知值保留為未知，不以空字串推論類型。

`EdgeRecord` 必須含來源與目標索引、原始接點數、來源位置或聚合證據、可選傳導物質與作用符號、其證據。連線強度、調節係數與目前可塑狀態不能覆寫這份記錄。

`ReceptorRecord` 必須含適用細胞／細胞類型、訊號名稱、證據來源、量測種類、未知狀態及工程映射版本。mRNA 表現值不可直接冒充已校準的反應強度。

## 06｜訊號、時間與輸入輸出的契約

### 6.1 共通容器，分開編碼

所有資料進入具名通道，例如 `vision`、`audio`、`text`、`spatial`。通道再透過可保存、可檢查的映射連到神經元。資料集不得直接依賴某版大腦的內部索引。

訊號至少包含 schema 版本、經驗與串流 ID、通道、訊號種類、開始時間、持續時間、位置／形狀、數值型別、單位、有效範圍、品質與編碼器版本。必須區分連續輸入電流、活動強度、離散放電事件、調節驅動及實驗性強制刺激。離散放電的強度定義不能和突觸權重混用。

不得在預設推論流程直接覆寫任意神經元膜電位。強制電位、強制放電或抑制某細胞屬干預模式，要另外授權於實驗設定，並記錄干預時間與對象。

### 6.2 時鐘

核心以整數步號推進，另保存每步對應的時間及單位。音訊取樣時間、影片影格時間、神經模擬時間與實際電腦執行時間分開。未經校準的人工模型使用 `model_step` 或 `normalized_time`，不能把它們寫成真實生理毫秒。

對輸入重取樣、對齊、同時事件排序及半步事件的處理必須固定規則。參考規則是：同一時間先依來源序號穩定排序，再以宣告的加總或覆寫語意整合。時間倒退、重複序號、負持續時間與未支援單位要拒絕，不能默默修正。

不同頻率的通道可以共用模擬時間軸。離線非因果前處理與線上因果前處理必須不同設定，例如使用未來音訊的置中視窗不可拿來量測即時延遲。

### 6.3 觀察、答案、回饋三分離

`Observation` 只放作答當下可取得的資訊。`Target` 由訓練器持有，用於計算錯誤。`Feedback` 含對應的行動 ID、實際產生與可取得時間、來源、分數與模型版本。

編碼器、核心及調節控制器在作答前都不能取得本題答案。語言生成的教師引導只允許已知前綴，不能輸入正在預測的 token。訓練器可以看到答案，不代表模型的前向運行也可以看到。

測試模式不得呼叫教師填補結果。延遲教師回應到達時，僅能影響之後的狀態與學習，不能回頭改寫已輸出的答案或偽造更早的可取得時間。

### 6.4 通道映射

支援按明確神經元集合、細胞類型、區域或固定隨機投影建立映射。映射必須保存來源、seed、投影參數、輸入輸出維度與神經元集合的雜湊。映射選用的神經元不存在時直接失敗。

模型可以使用人工感官，但要標記為人工映射。未知資料不能被自動塞進「看起來適合」的腦區。生物模式使用有證據的映射；人工 AI 模式可以由 agent 選擇低風險映射並記錄對照。

### 6.5 輸出端與資訊洩漏

每個任務宣告可讀的神經元集合、讀取時機與狀態欄位。至少提供只讀當下神經活動的低容量輸出端。更強的解碼器是另一個設定，須把參數量、訓練來源、狀態與外部依賴列入報告。

核心能力實驗不得繞過核心，把原始觀察或題目直接交給解碼器。影音的還原器只接核心產生的表示及宣告的時鐘，不接原始提示文字。工具呼叫模式是例外，但必須使用另一種能力標籤。

## 07｜大腦模型、參數與狀態的分離

### 7.1 四種獨立資料

**解剖資料**保存真實接線與註記。**基礎參數**保存可訓練連線強度、神經元參數、編碼與讀出參數。**個體狀態**保存電位、放電史、暫時可塑性、化學狀態與內在資源。**訓練器狀態**保存最佳化器、資料游標、教師佇列、隨機產生器與重播資料。

分開保存才能區分「讀入同一顆腦的新個體」「接續原個體」「重新開始一段任務」與「清除所有經驗」。不得用一個 `Reset()` 默默完成以上所有操作。

### 7.2 必須提供的模式

| 模式 | 基礎參數 | 暫時連線狀態 | 神經與調節狀態 |
|---|---|---|---|
| 固定模型評估 | 不修改。 | 固定或重設後不修改，依設定。 | 可以依輸入正常演化。 |
| 適應性評估 | 不修改。 | 允許規定的局部更新。 | 正常演化。 |
| 運行中梯度學習 | 僅授權的參數更新。 | 依設定更新。 | 正常演化。 |
| 離線訓練 | 依訓練遮罩更新。 | 可跨指定經驗保留或重設。 | 明確指定生命週期。 |
| 生物干預 | 依實驗規則。 | 依實驗規則。 | 可以施加已記錄的鉗制、阻斷或外部調節。 |

「關閉學習」必須定義是否連局部可塑性一起關閉。只關掉 Adam，仍允許快速連線狀態改變，就不是完全固定的推論。

### 7.3 每個神經元的計算表示

純量狀態與每節點多維向量兩種模式都需支援。前者便於與簡化生理對應，後者供一般圖計算 AI 實驗。多維模式必須記錄維度，不能用「神經元數相同」掩蓋計算容量增加。

按類型共享參數與逐神經元／逐連線參數都要有實作。共享模式降低自由參數；逐項模式用於完整可訓練試驗。兩者均保存展開與回收梯度的索引對照。

### 7.4 凍結與更新遮罩

使用者可按參數類別、神經元集合、連線集合、腦區或細胞類型指定哪些參數能更新。遮罩也要作用於最佳化器的權重衰減與動量，不能只把目前梯度設零，卻仍讓參數被動量改動。

對作用符號有可靠依據的連線，主模式固定符號，只學幅度。未知連線允許明確的工程假設或可訓練符號，但需要不同模式與報告。不得把所有谷胺酸、多巴胺或血清素連線一律指定相同正負。

## 08｜神經動態的參考實作與數值規則

以下是必須能被測試的參考模型。Agent 可以改良求解方法，但外部設定須標記方法與版本，不能改方程式後仍宣稱是同一模型。

### 8.1 連續動態基準

令 `v_i(t)` 為神經元狀態，`y_i(t)=phi(v_i(t))` 為輸出，`tau_i>0` 為狀態消退時間。採同步更新，所有連線只讀前一步或更早的狀態。

```text
lambda_i = exp(-dt / tau_i)
I_i(t) = external_i(t) + sum_j w_ji(t) * y_j(t-delay_ji)
v_i(t+1) = lambda_i*v_i(t) + (1-lambda_i)*(b_i + I_i(t))
y_i(t+1) = phi(v_i(t+1))
```

此式的輸入與電位採模型一致的正規化單位。若要使用物理電流，需另外加入電阻或導電度與單位轉換，不可直接套入。它對每一步固定的輸入使用指數漏電更新，但整個遞迴網路仍是離散近似。必須有縮小時間步的收斂比較。

至少提供兩種已測試的 `phi`，例如受限連續輸出與平滑正值輸出。選哪種會影響訊號的正負含義，要記錄，不得默默替換。連續模型沒有「放電閾值」時，不為湊參數加上無作用欄位。它可有不同意義的反應閾值，但名稱與方程式需區分。[S06]

### 8.2 LIF 與適應性閾值

LIF 指訊號累積、隨時間漏失，達到門檻就產生離散放電的簡化神經元。實作至少需處理漏電、靜止值、門檻、重設、不應期、突觸衰減與延遲。

```text
v_candidate = membrane_update(v, synaptic_input, dt)
theta_effective = bounded(theta_base + adaptation + homeostasis + modulation)
spike = 1 if (not_refractory and v_candidate >= theta_effective) else 0
v_next = v_reset if spike == 1 else v_candidate
adaptation_next = adaptation*exp(-dt/tau_adapt) + beta*spike
```

`theta_base` 可訓練；`adaptation` 是近期活動產生的狀態；`homeostasis` 是慢速活動穩定機制；`modulation` 來自化學系統。四者分別可開關與觀察。適應性閾值的工程參考可借用脈衝網路研究，但不得宣稱全腦每種果蠅神經元皆使用同一規則。[S09]

參數使用有界轉換或明確投影，保證正時間常數、可接受閾值範圍及 `v_reset < theta_effective`。若調節破壞這些條件，要報告並拒絕或按事先指定的投影規則處理，不能無聲截斷。

不應期期間膜電位保持、輸入累積或輸入忽略，需在模型設定中選定一種已測試語意。每步最多一個 spike 的設定會限制最高可表示頻率；不能把離散步的上限當成生物頻率。

### 8.3 閾值如何訓練

硬判斷的真實導數幾乎處處為零。採替代梯度時，前向仍產生 0／1 事件，反向使用宣告的平滑近似 `psi(v-theta)`。[S08]

```text
surrogate_d_spike_d_v = psi(v - theta)
surrogate_d_spike_d_theta = -psi(v - theta)
```

必須記錄近似函數、寬度、尺度、閾值邊界及是否讓梯度跨過重設步驟。基礎閾值使用有界參數化時，反向需再乘上該轉換的導數。

**測試不可拿硬 spike 的有限差分當作替代梯度的正確答案。** 連續／平滑參考模型可做有限差分；硬 spike 需測前向事件時序，以及反向是否符合所宣告的替代規則。再用小任務證明閾值確實更新且影響學習。

### 8.4 按類型混合

混合模式應是每群神經元選擇適用的更新規則，而不是所有神經元無條件同時輸出兩次訊號。統一核心時鐘與跨類型的輸出契約，明確規定脈衝如何形成突觸輸入、連續輸出如何進入脈衝細胞。

延遲為零時仍以同一步開始時的狀態運算，避免代數循環與更新順序依賴。需要同時求解的模型必須另設求解器與收斂規則，不能由 goroutine 排程決定結果。

### 8.5 活動穩定機制

參考慢速規則可讓過高活動提高門檻，過低活動降低門檻，並限制更新速度與範圍。目標活動率屬實驗設定，不宣稱來自 MaleCNS。

需同時監測長時間沉默、全群放電、非有限值、梯度異常、權重邊界命中率及能完成任務的比例。低活動不等於低能耗，更不等於健康神經系統。沒有實際功率量測時，只能報告活動或運算量代理指標。

## 09｜稀疏運算與梯度的必備驗證

### 9.1 不建全腦稠密矩陣

主要儲存與計算複雜度應依存在的連線數 `E`，而非 `N*N`。CPU 參考路徑可以使用依目標分組的稀疏索引及固定順序加總；實際結構交由 agent 決定。小型稠密版只可用於比對，不可自動套到全腦。

原始接點數可乘上可訓練幅度形成模型權重，但任何縮放、正規化或門檻都要記錄。標準化不能覆寫原始接點數，也不能無聲刪掉小權重邊。

### 9.2 最小數值試金石

對三顆神經元，固定以下邊及順序：`1→2=0.5`、`3→2=-0.25`、`2→3=0.75`。令輸入為 `[2,4,8]`，純線性聚合的輸出應為 `[0,-1,3]`。

若輸出端上游梯度為 `[1,2,3]`，三條權重的梯度依前述順序應為 `[4,16,12]`，輸入梯度應為 `[1,2.25,-0.5]`。這是本文直接計算的人工測試資料，不是生物量測。

一般式為：

```text
output[target] += weight[edge] * input[source]
grad_weight[edge] += grad_output[target] * input[source]
grad_input[source] += grad_output[target] * weight[edge]
```

加入 batch、向量節點、共享參數與延遲後仍要與相對應的小型參考實作一致。共享參數的梯度需要加總到同一個參數，不可平均或覆寫，除非損失的縮放定義明確要求。

### 9.3 必備操作

需要前向與反向的操作至少有：稀疏加權聚合、連續狀態更新、脈衝替代反向、參數有界轉換、選擇性讀出、稀疏輸入映射、化學控制器的可微路徑，以及可選的可微可塑性更新。

輸入是任意資料，不代表所有資料類型都可微。文字切詞、離散動作採樣與資料解碼的邊界要明示。不可聲稱梯度穿越未實作的操作。

### 9.4 容差與決定性

工程預設：float32 前向與參考值比較使用 `atol=1e-5, rtol=1e-4`。平滑模型的 float64 有限差分，先以相對誤差 `1e-4` 作測試門檻，近零梯度另看絕對誤差。這些是測試起點，必要調整需附誤差分析，不可因測試失敗隨便放寬。

單執行緒參考模式應在相同硬體、編譯器與版本上可重現。跨 CPU／GPU 與不同加總順序只承諾通過數值容差，不保證位元完全一致。

### 9.5 反向路徑不得斷裂

測試必須追蹤梯度從任務損失經過讀出、核心連線、神經參數，回到可訓練輸入映射。至少證明核心的非零梯度、遮罩作用、一次更新結果及損失下降。只測 `Forward()` 有輸出或只有讀出端有梯度，均不算完成。

## 10｜訓練方法、局部可塑性與持續學習

### 10.1 必須支援的訓練途徑

離線監督學習、跨時間反向傳播、限制回推長度的訓練、運行中小批次更新、教師蒸餾、局部連線可塑性、神經調節控制的可塑性、模仿學習及至少一套完整行動回饋學習方法均在完整範圍內。建議以 PPO 作行動回饋參考，其他可驗證且契約相同的方法可以替換。[S20]

這些方法不必全部同時啟用。能力矩陣必須逐項聲明可搭配的動態、損失、裝置及狀態模式，拒絕不支援組合。

### 10.2 跨時間反向

完整回推用於小型參考；大型實驗可使用有限時間窗與重新計算節省記憶體。切斷梯度與清除神經狀態是不同操作。時間窗之外仍可保留個體狀態，但不能宣稱損失可追溯到無限久以前。

重新計算必須保存所需隨機狀態、輸入、調節狀態與快速權重起點。禁止在回算時第二次執行有副作用的學習更新、再次取得不同教師回應，或再消耗環境資源。

對 CTC 等整段序列損失，不能把未對齊的文字任意切成幾段當作每窗標籤。應先取得合法序列分段，或保存／重算整段輸出所需資訊，再按正確損失回傳梯度。[S19]

### 10.3 局部可塑性

參考模型將有效權重分成基礎部分與個體可變部分，並為指定連線保存近期參與紀錄：[S10]

```text
eligibility_next = decay_e*eligibility + pre_activity*post_activity
plastic_next = bounded(decay_p*plastic + learning_gate*eligibility_next)
```

這是人工參考規則。單純相乘不是每種果蠅突觸的通則，也不足以保證任意任務可以用獎懲學會。需支援使用者替換更新規則，以及脈衝前後時序相關的規則。不同規則各自有測試與證據標籤。

具有固定作用符號的模式，不能用 `base + plastic` 導致跨零翻轉。可把快速變化施加在非負幅度的有界或對數參數上；具體做法需與基礎幅度、最小值及導數定義一致。

局部規則、梯度更新與長期穩定化若同時作用於同一參數，要定義唯一順序與合併方式。不得讓不同 goroutine 同時寫入，也不得讓 Adam 動量引用已被其他規則改寫而未處理的值。

### 10.4 長期保存與重播

支援不重播、容量受限的舊經驗重播，以及按任務或時間維持樣本比例的重播。每個策略需記錄容量、抽樣方法、seed、資料隱私政策及樣本移除規則。

基本功能包括：先學 A、再學 B、重測 A、循序增加任務、環境規則改變後重新適應。不得將每個任務都重新初始化的獨立訓練稱為持續學習。

模型可有暫時、較慢與基礎參數三層記憶，但「穩定化」不是把所有暫時更新永久相加。要定義觸發、幅度、保留與回復規則，並驗證不會重複計入同一經驗。工程穩定化與生物長期記憶證據分開報告。

### 10.5 回饋學習與探索

獎勵只提供結果，不自動指出每條連線如何修改。行動學習需要完整的探索策略、行動機率、價值估計或對應的信用分配方法，不能只在 reward 非零時任意增加所有活躍權重。

若使用遞迴 PPO，收集經驗時要保存策略版本、行動機率與初始狀態。更新時處理 burn-in、終止與時間上限，且不能沿用不一致的新舊快速權重或調節狀態。必須有小型環境的可重現學習證據與機率比值測試。

### 10.6 測試污染防護

一般測試資料不進入重播，不用於調參。適應性測試則事先分成允許學習的部分與最後評分部分，明示有哪些回饋可用。每個測試個體的快速權重與化學狀態是否重設要固定，避免利用前一題的答案污染後一題。


<a id="chapter-11"></a>

## 11｜化學調節、荷爾蒙與內在狀態

### 11.1 三個層次不能混成一個數字

第一層是訊號來源：外界回饋、指定調節神經元、人工控制網路、虛擬身體或預先記錄的干預。第二層是具有時間演化的調節狀態。第三層是接收細胞或連線產生的選擇性效果。

框架共同處理上述計算介面，但保留 `neuromodulator`、`neuropeptide`、`endocrine`、`engineering_control` 的種類及證據。化學分類不自動決定快慢，有些內分泌效果也可能較快。不可把所有多巴胺定義為正獎勵，或把血清素限定為單一功能。[S14][S15][S16]

### 11.2 必須有的訊號來源

| 來源 | 功能與限制 |
|---|---|
| 外部控制 | 可指定濃度／驅動的時序，供對照與干預；輸入要經合法性檢查。 |
| 神經活動驅動 | 由具名神經元或群體的輸出產生釋放。不能自動假設未知神經元是調節細胞。 |
| 小型可訓練控制器 | 讀取已允許的歷史活動摘要、先前回饋及內在狀態，產生有限個控制值。 |
| 虛擬內在資源 | 由能量、資源或其他已定義環境狀態產生調節；只有任務需要時才啟用。 |
| 記錄重播 | 重播既有調節時序以比較同一核心的結果，不能重新向外部服務取得不同值。 |

人工控制器預設不得直接讀取完整題目並輸出答案，亦不得讀取目前測試的正確標籤。其參數、計算量與訓練資料必須計入整體模型容量。

### 11.3 調節狀態的參考方程式

對區域 `r`、通道 `k`，以非負濃度狀態 `c[r,k]`、非負釋放率 `q[r,k]` 與正時間常數 `tau[k]` 定義工程基準：

```text
lambda = exp(-dt / tau[k])
c_next[r,k] = lambda*c[r,k] + tau[k]*(1-lambda)*q[r,k]
```

在固定釋放率下，此式趨近 `tau*q`。若要表達基準濃度下降，應降低釋放率或調整清除率，不能輸入負濃度。需要正負值的量另命名為「相對基準調節效果」。無生理校準時採正規化單位。

先提供獨立區域的狀態與明確區域傳輸矩陣即可，不要求三維分子擴散。增加區域傳輸時，需處理非負性、流出與流入及步長穩定性。神經接線與化學傳輸路徑是不同資料，不得把化學廣播偷偷記成新的神經突觸。

### 11.4 接收端與反應飽和

可選工程反應曲線為：

```text
occupancy(c) = c^n / (Kd^n + c^n)
```

其中 `Kd>0`、`n>=1`，皆為模型參數，並非已知果蠅數值。程式要使用穩定實作避免高次方溢位。接收端再用有界映射產生增益、閾值或學習調節；多個受體或通道的混合作用亦需明確。

接收端資料需區分「實驗指出不反應」「未知」及「假設反應」。可按細胞類型共享係數，也可逐細胞設定。未知係數可訓練，但不能因此稱為測得受體表。

### 11.5 必須實作的效果

| 效果 | 對模型的作用 | 必要檢查 |
|---|---|---|
| 當下敏感度 | 放大／縮小或偏移指定細胞收到的訊號，參考 FiLM 的計算形式。 | 控制值為中性時等同未啟用。不能直接產生答案。 |
| 有效閾值 | 暫時調整指定脈衝細胞的放電門檻。 | 與可訓練基礎門檻分離，受限且可恢復。 |
| 局部學習閘門 | 決定指定連線是否利用近期參與紀錄更新。 | 閘門關閉時快速連線不得新增學習變化。 |
| 學習時間窗 | 改變近期參與紀錄的衰退速度。 | 正時間常數、有界、延遲回饋測試可區分。 |
| 記憶使用 | 改變已儲存狀態對指定輸出的影響。 | 不應把這種效果本身誤算成永久學習。 |
| 穩定化閘門 | 影響暫時變化寫入較慢狀態的條件。 | 不可重複寫入或繞過更新預算。 |

FiLM、ANML 及 Backpropamine 提供的是人工模型設計參考，不是以上全部效果的果蠅生理證明。[S10][S11][S12]

### 11.6 獎勵、懲罰與損失的角色

環境的原始獎懲不可由模型自行改寫。可以另計算相對預期的好壞程度，作為人工調節系統的輸入。原始分數、預期值、轉換結果及真正作用於連線的值必須分別保存。

損失函數用於訓練基礎參數或調節器本身。它不是腦內可自然取得的荷爾蒙濃度。一般推論時，沒有正確答案就不能使用依賴答案的損失來產生調節，除非明示這是一個有教師的適應流程。

對內在需求，可定義環境結果是否減少資源不足，但不能讓模型直接改資源計分規則。將此機制限定在有實際內在資源的任務，並與固定獎勵比較。[S17]

### 11.7 生物命名設定的完成方式

必須提供生物證據登錄與可執行干預範例，至少涵蓋「改變時機影響記憶」及「狀態影響記憶表現」兩種設計。範例若使用人工數值，只能命名為 `ecdysone_inspired` 或 `npf_memory_expression_hypothesis`，並明示不是定量重現。[S14][S15]

要標成某荷爾蒙的定量模型，需補上原研究方法、原始或可追溯量測資料、參數估計、未參與擬合的干預測試與結果。只讓曲線看起來類似不夠。若資料不可取得，保留明確的研究限制，而非補造數字。

### 11.8 必須完成的對照

至少比較無調節、直接獎懲控制學習、具衰退的固定規則調節、可訓練控制器、只改活動、只改可塑性及兩者並用。另加相近參數量的一般記憶控制器，以排除單純增加容量的影響。

干預需包括濃度固定、輸入關閉、受體阻斷、延遲打亂、區域對調、單一通道移除及恢復。需要分別量測活動變化、快速權重變化、基礎參數變化及任務結果。

## 12｜教師、LLM 蒸餾與外部工具

### 12.1 統一教師契約

教師可以是人工標籤、離線資料、另一個模型、LLM 或多模態模型。回應至少記錄教師識別與版本、請求 ID、來源輸入雜湊、答案型別、答案內容、時間、可選信心與計費／使用量資訊。

教師資料與測試輸入分開保存。所有遠端請求需明確設定端點、逾時、有限重試、速率、預算與允許傳送的資料欄位。預設使用離線教師；預設雲端預算為零。

### 12.2 必須完成的蒸餾方法

第一種是以教師的答案或動作序列作標籤。文字重新使用學生自己的 tokenizer，不直接沿用不同詞表的 token ID。

第二種是比較教師與學生的機率分布。只有詞表、類別或對齊規則明確一致時，才可使用帶溫度的分布蒸餾。需要保存溫度、縮放與損失混合比；只拿到 top-k 機率時不得冒充完整分布。[S18]

第三種是具名中間表示對齊，作為可選實驗。任何用於對齊的可訓練轉換器都算模型的一部分，要量測其容量與獨立能力。

### 12.3 教師拿掉的測試

每個蒸餾範例必須有完全關閉教師與網路存取的學生評估。測試時仍呼叫老師的模式另命名為 `teacher_assisted`，不得稱為獨立學生。

評估不只看學生像不像老師，也要看真正目標上的結果。老師可能錯誤，因此保留人工或獨立來源的評估集，以及已知錯誤標籤的穩健性測試。

### 12.4 現成服務整合的範圍

必須有離線 JSONL 教師及可測試的通用 HTTP 教師 adapter。實作時依選定服務的官方文件做具體 adapter，不能用「大概相容」當支援證據。沒有付費授權時用本機測試伺服器驗證協定，真實遠端呼叫標示未驗證。

不能因為支援 ONNX 就宣稱能運行所有大型語言或影音模型。可匯入的操作、模型型別、精度、狀態及記憶體都要先檢查。[S04]

### 12.5 外部工具與核心能力分離

外部 OCR、語音辨識、LLM 或影音服務可以當教師、輸入前處理或工具，但必須標示實際角色。教師回傳文字一律當資料，不執行其中的命令，也不能用教師指示修改安全設定或傳送額外檔案。

工具模式需有顯式請求、結果驗證與錯誤處理。模型自行生成的工具參數不得繞過允許清單。這些功能不將 CoImNet 擴大成任意電腦操作 agent。

## 13｜五類任務的完整實作要求

### 13.1 共通完成條件

每個任務都必須提供：資料規格與讀取器、前處理、編碼與映射、核心執行、輸出端、損失、訓練、獨立推論、評估、保存恢復、離線範例、真實資料匯入範例及對照流程。

人工資料用於確定程式能運作，不代替真實資料上的能力評估。所有範例皆標示資料範圍、語言、解析度、序列長度及外圍模型。原生核心模式的輸出不能繞過核心。

### 13.2 OCR：影像轉文字序列

**輸入與資料：** 支援 PNG／JPEG 的單行文字影像與對應 Unicode 文字。另提供頁面影像與文字區塊／閱讀順序的資料契約，以及將區塊送入同一辨識器的流程。基礎頁面切分可以採已說明限制的規則，但不能宣稱適用任意複雜版面。

**處理：** 保存影像尺寸、色彩空間、縮放方法、文字方向與區域座標。編碼可先用低階像素區塊或小型卷積模型，並提供固定編碼器與可訓練編碼器的對照。單行影像可按空間順序轉成序列。

**輸出與訓練：** 輸出字串及可選區域資訊，不能只輸出單字分類。參考採 CTC，亦可提供明確因果的序列生成模式。CTC 的空白符號、重複字、長度限制與解碼規則必須通過測試。[S19]

**評估：** 報告字元錯誤率 CER、整句正確率及空輸出比例。CER 以替換、刪除與插入的總數除以參考字元數，空參考要另定義，不得除以零。至少保存未正規化原文與有版本的評估正規化，不要默默移除標點或簡繁轉換。

**必要測試：** 重複字、空白、繁體中文字串、大小寫、不同字型／背景、未見文字組合、空影像及破損檔。字型、來源文件或版面母本不得跨訓練／測試洩漏。不得夾帶來源不明或沒有再散布授權的字型檔；測試使用 agent 自行取得且授權清楚的資產或使用者提供資產。

### 13.3 語音轉文字：真正的逐段轉錄

**輸入與資料：** 至少支援 WAV PCM 音訊與文字稿、取樣率、聲道、說話者與錄音來源。壓縮音訊格式可透過顯式的解碼器整合，不可假裝已原生支援。資料分割以說話者／錄音場次為單位，避免同一音檔片段出現在兩邊。

**處理：** 明定重取樣、混音、音量正規化及頻率特徵。參考可以使用短時間頻譜與 log-mel 頻帶特徵，但要固定視窗、步長與濾波器版本。串流模式不得使用尚未到達的音訊或整段音檔的未來統計。

**輸出與訓練：** 輸出完整文字序列；參考採 CTC 或可驗證的序列到序列方法。要有整檔模式及串流分塊模式，保存未完成音訊片段與解碼器狀態。斷線、尾端不足一窗與最終 flush 必須有預期行為。

**評估：** 報告 CER／WER、語言與斷詞規則、音訊長度、推論時間及串流延遲。沒有人工時間標記時不能捏造時間對齊精度。純音調或聲音種類分類只能作內部測試，不算完成語音轉文字功能。

### 13.4 語言生成：學生自己預測下一段文字

**輸入與資料：** UTF-8 文件、段落或有角色標記的對話資料。Tokenizer 必須可保存與重現，至少提供可處理任意 Unicode 的位元組基準，以及可替換詞表的介面。格式、角色與特殊 token 要在 tokenizer 設定中保存。

**訓練：** 以已知前綴預測下一個 token，遮掉填充與不應計分的前綴。資料切分以完整文件／來源為單位。可以使用老師產生的文字，但保留老師來源並去除測試重複內容。

**生成：** 支援起始狀態、最大長度、結束 token、貪婪與可重現採樣。串流位元組解碼需處理 UTF-8 尚未完整的字元；不能把錯誤字元靜默刪掉後宣稱有效輸出。合法性約束若影響採樣，要在設定中保存。

**評估：** 報告 token 化版本相同條件下的負對數似然與 perplexity，以及任務正確性／生成有效率。不同 tokenizer 的 perplexity 不可直接排名。規則語言的小任務要能展示核心學習；自然語言品質則必須用另外的保留資料量測。

**能力界線：** 不能以接入外部 LLM 或照抄教師文字的程式取代學生生成。沒有實驗前，不宣稱中文對話、推理或知識能力已達到特定等級。

### 13.5 文字轉影音：生成、還原與工具控制分開

必須實作三條清楚標示的流程：

**核心生成流程：** 文字經編碼與核心，核心產生像素／音訊區塊或可還原的表示，再由受控解碼器還原。訓練期間目標影音只供損失與必要的教師引導；推論時解碼器不讀原始提示文字。需報告編碼器、核心、解碼器的參數與訓練能力分工。

**固定還原器流程：** 使用已訓練且鎖定的影音壓縮／還原模型，核心學會產生它接受的表示。需驗證表示分布、時間對齊與獨立解碼品質，並明示既有還原器提供的能力。

**外部工具流程：** 核心輸出工具請求，由外部模型產生影音。此模式測的是控制工具，不算核心自身影音生成。外部呼叫需按授權、預算與資料政策執行。

參考流程至少能從文字條件生成低解析度影格序列與對齊音訊，輸出 PNG／WAV 及時間線清單。可選影片封裝器將兩者封裝為一般媒體檔。沒有封裝器時，原生影格與音訊仍需完整產出，不可回傳空路徑。封裝程序使用參數陣列，不拼接 shell 命令。

人工測試可以使用可控圖形、軌跡與聲音事件，但必須分開展示影像、時間變化、聲音及跨兩者同步是否受文字條件控制。這只證明有限任務的生成，不是自然場景、真人語音或音樂品質的證據。

真實影音資料 adapter 需接受使用者授權的文字與對應影音檔、影格時間、音訊取樣率及授權欄位。訓練、推論與評估不能只留介面。品質評估至少報告保留條件的內容符合度、時間一致性、音訊長度／同步誤差及外圍模型對照；像素 MSE 好看不代表感知品質良好。

### 13.6 空間與導航

原生參考環境為可重現的二維環境，包含位置、方向、障礙、有限視野、目標與行動。觀察、行動、結果、終止與時間上限分開。至少有記住目標位置、繞過障礙、環境改變後適應及語言目標條件的任務。

訓練可用專家路徑模仿，再以完整行動回饋方法學習。專家提供訓練標籤，不得在評估時偷偷提供最短路徑或不可見目標座標。部分可觀察任務不能讓評估者專用狀態流入輸入編碼器。

提供明確座標系、長度／角度單位、相對與絕對位置、方向環繞及速度的資料契約。外部三維／物理模擬器可接同一契約，但不要求重建真實果蠅全部肌肉與飛行力學。

評估包括成功率、達成目標步數、碰撞、累積外部獎勵、資源成本與遇到新地圖的表現。基準至少有隨機策略、無記憶控制器及真實接線的重新接線對照。

## 14｜同一核心的多模態與能力歸因

### 14.1 共同學習不等於多個模型同名

至少完成一個單一模型版本、共用核心參數與明確個體狀態的跨任務訓練。可以有不同模態的輸入轉換與任務讀出，但不能每個任務建立一個獨立核心，再合稱同一顆腦。

每次結果記錄 `brain_topology_hash`、`base_parameter_hash`、`state_lineage`、任務識別及 adapter 版本。多個使用者或獨立測試個體不得共用個體狀態。

### 14.2 必備共同經驗資料

同一實體的影像、文字、音訊與位置配對需有明確 `entity_id`／`event_id`。這些 ID 供整理資料與評估，預設不直接送進模型。不能把標籤 ID 當低階感官訊號讓模型走捷徑。

需有同步與非同步配對，並保留沒有該模態的情況。缺少音訊不等於全零音訊，缺少位置不等於原點。提供缺失標記與使用規則。

### 14.3 共同訓練

支援交錯任務、同段經驗多模態及模態缺失。各任務損失的尺度、混合權重、取樣比例與更新頻率都可設定且記錄。不得讓資料量最大的任務無聲決定所有參數更新。

若使用對比配對或共享表示損失，要排除同一實體被誤當負例，並把可訓練對齊轉換器納入容量比較。共同概念是否形成，要靠跨模態與未見組合的測試判斷，不能靠視覺化接近就斷言。

### 14.4 必備對照組

至少比較：正常核心學習、固定核心只學外圍、低容量固定外圍只學核心、參數量相近的一般網路、保持入度／出度等條件的重新接線圖、移除核心後重新訓練的模型，以及外加調節器的容量匹配對照。

重新接線須說明保留了哪些條件，並檢查邊方向、重複、自我連線、作用符號與連通性。不得以完全不同的參數量或訓練預算製造優勢。只關掉訓練好的核心造成退步，證明的是依賴性，不是原始生物接線的優越性。

### 14.5 持續學習矩陣

保存每個訓練階段對所有既有任務的評估結果，而非只報最後新任務成績。遺忘可定義為某任務歷史最佳成績與當前成績之差，但不同方向的指標先統一其意義。記憶測試需使用固定調節狀態，另設狀態切換測試，避免把暫時抑制表現當成遺忘。[S15]

至少使用多個固定 seed，報告平均、離散程度、全部個別結果與失敗執行。若宣稱勝過對照組，要有預先選定的比較方法與不確定性區間。不得只挑最好的一次。


<a id="chapter-15"></a>

## 15｜保存、恢復、版本與資料安全

### 15.1 三種不同的保存物

**模型包**包含拓撲指紋、基礎參數、神經與調節設定、編碼／解碼器、單位、證據登錄及相容版本。它供新個體啟動，不必包含某次經驗的狀態。

**個體快照**在模型包基礎上加入神經電位、輸出史、不應期、延遲佇列、適應閾值、慢速穩定狀態、快速連線、近期參與紀錄、化學濃度與內在資源。用於接續同一個體。

**訓練快照**再加入最佳化器、排程器、累積梯度、資料游標、重播資料與索引、各隨機產生器、教師請求狀態及更新交易序號。只存權重不得稱為可恢復訓練。

### 15.2 快照原子性

參考方法是在更新完成的同步點建立快照，再寫入暫存目錄、檔案校驗與完成標記，最後原子更名。允許其他符合一致性的方案。寫到一半的快照不可出現在可恢復清單。

恢復必須檢查 schema、拓撲、參數形狀、精度、模型程式版本、映射、tokenizer 及狀態生命週期。錯誤要指出不相容項目，不能靜默補零或隨機初始化缺少欄位。

### 15.3 恢復驗收

在同一參考環境中，連續執行 K 步，與執行到中途保存、重新啟動再繼續的結果比較。必須檢查輸出、基礎與快速參數、化學狀態、環境、最佳化器與資料順序。

線上外部教師不可保證重新回覆完全一致，因此精確恢復模式需使用已保存的教師回應或具相同請求 ID 的可重播來源。未完成外部請求是否重送，要有去重與成本規則。

### 15.4 個體隔離

同一基礎模型可以建立多個個體，每個個體有獨立的可變狀態與隨機流。不可因共用陣列導致某位使用者的經驗改變另一個體。共享學習必須是另外開啟、有明確同步與權限的模式，不是預設。

### 15.5 敏感資料

文字、音訊、影像、教師提示及重播資料可能包含使用者資料。預設不記錄原始內容到公開日誌，不加入遠端追蹤。除錯輸出要可遮罩、限制保存量與清理。

不得將 API 金鑰、登入 token、私有教師回應或使用者資料提交到 Git。快照是資料而非可執行程式，讀取時檢查總大小、型別、維度與檔案路徑，禁止不受控物件反序列化與路徑跳脫。

### 15.6 相容性與遷移

外部 schema 使用明確主次版本。未知必要欄位、未知演算法版本或未註冊擴充要報錯。遷移工具只產生新檔並保留來源，附前後指紋與資訊損失報告，不能覆寫唯一原件。

## 16｜SDK、CLI 與實驗設定

### 16.1 SDK 的使用者能力

SDK 使用者應能載入資料、建立核心、建立獨立個體、註冊自訂編碼／動態／學習／調節／任務、逐步提供觀察、取得輸出、回傳事後結果、訓練、評估、干預、觀察局部狀態、保存與恢復。

公開 API 使用 Go 的錯誤回傳與可取消的 context，不以 panic 回應普通輸入錯誤。長任務支援進度、取消及資源釋放。內部狀態的可變存取需受控，不能公開裸指標讓外部在訓練途中任意寫入。

本文件不強迫套件名稱或介面方法簽章。Agent 應用可執行例子驗證 API 易用性，並將具體簽章寫入 Go 文件；不得把偽程式碼直接當作既有 Insyra API。

### 16.2 CLI 外部行為

以下指令是**待建立的 CoImNet CLI 契約**，並非目前已存在的命令。Agent 可調整參數排版，但需要保持每種能力，並同步所有範例與測試。

| 指令群 | 必須完成的行為 |
|---|---|
| `doctor` | 報告 Go、Insyra、資料格式、裝置、可用記憶體、外部解碼器與缺少能力。 |
| `data fetch / inspect / import / validate` | 下載、查看 schema、建立標準圖、檢查篩選與校驗，不只列印成功。 |
| `model inspect / validate` | 顯示拓撲、參數、模式、證據、映射與預估資源。 |
| `run` | 依完整設定執行訓練／推論／評估，支援 dry-run 與取消。 |
| `resume` | 從可驗證快照接續，不因新預設改變原實驗。 |
| `evaluate` | 固定或適應性評估，將模式寫進結果。 |
| `ablate` | 建立具名對照設定、使用同一資料與預算，保留各結果。 |
| `benchmark` | 量測匯入、前向、反向、局部學習、調節與快照成本。 |
| `export` | 匯出有能力邊界的模型或結果；不支援的格式明確拒絕。 |
| `examples list / run` | 執行完整範例，顯示資料與外部依賴，不在無授權時呼叫付費服務。 |
| `report` | 產生包含設定、成績、限制、來源及完成狀態的報告。 |

`--dry-run` 驗證設定、依賴、資料與資源，不修改參數、不啟動教師呼叫。輸出 JSON 模式要有 schema 版本，方便其他 agent 判讀。

組態必須包括資料版本與篩選、模型型別、時間單位與步長、參數共享方式、可更新遮罩、訊號編碼與映射、任務與損失、學習規則、調節器、狀態重設、教師設定、seed、裝置、資源上限、資料切分與輸出位置。

設定檔要嚴格拒絕未知欄位。預設值可以存在，但執行時必須輸出全部展開後的設定。環境變數與 CLI 覆寫的優先序固定，並保留覆寫來源。金鑰只保存參照，不寫入展開設定。

## 17｜效能、記憶體與全腦執行

### 17.1 資源預算在執行前估計

用 `N` 表示神經元數、`E` 表示實際運算邊數、`C` 表示每節點狀態維度、`B` 表示同時處理的個體數、`T` 表示保留反向歷史的步數。預估至少包含圖索引、基礎參數與最佳化器、目前神經狀態、快速連線、近期參與紀錄、延遲、反向歷史、編碼器、讀出器、調節器、資料與暫存緩衝。

以下僅為算術示例，不是 MaleCNS 實測：若 `E=15,000,000`，每邊各存一個 float32 的權重、梯度、Adam 一階與二階狀態，總計 `16E`，約 240 MB。再為每個個體每邊存兩個 float32 狀態，增加 `8BE`。若把兩份邊狀態的 128 步歷史全存下來，單個體便約增加 15.36 GB，尚未計入其餘項目。

因此「稀疏權重放得下」不等於「訓練放得下」。不得只依顯示卡型號（例如 RTX 4070）推定全功能都可執行。實際需求由測試產生。

### 17.2 三種規模

`fixture` 是人工小圖，用於離線 CI 與數值驗證。`real-subgraph` 是經明確選取的真實子圖，用於真實資料整合。`male-full` 使用宣告視圖中的完整主要圖。三者的報告與快照不能混稱。

預算不足時，預設拒絕啟動並提供估算。使用者明確選擇 smaller profile 後才縮小，不得自動裁圖、降低解析度、減少時間窗或更改可訓練參數。

### 17.3 CPU 路徑

提供單執行緒參考與受控並行模式。依目標節點分區或其他無競態方法分配工作，避免每個神經元一個 goroutine。熱路徑不得逐步建立大量 map、字串或資料表。

監測配置量、垃圾回收、加總順序、資料複製與跨介面成本。任何為加速而改變數值語意的做法需獨立模式與誤差報告。

### 17.4 GPU 路徑

完整效能目標包含至少一個裝置後端的稀疏前向與反向，以及必要的狀態更新。選型交由 agent，優先評估能與現有 Go／Insyra 生態整合的路徑，但必須做最小實測，不把一般矩陣加速當成果蠅核心已加速。[S04]

要量測傳輸、編譯／初始化、暖機與穩定執行時間。可行時讓狀態留在裝置，不每一步整顆腦往返 CPU。裝置記憶體與可用擴充需執行前檢查。

沒有 GPU 的 CI 可測協定、錯誤及 CPU 回退，但不能宣稱裝置測試通過。無法完成裝置測試時，保留 `blocked_hardware`，不影響繼續其他已授權工作；整體交付仍需明示未完成項目。

### 17.5 全腦驗證最低內容

必須實際完成主要資料的下載／匯入／統計、完整圖前向、一次涵蓋已宣告可訓練參數的反向更新、局部可塑性與調節狀態啟用、保存恢復，以及資源報告。為降低成本可用短序列驗證，但不得只計算一小部分節點卻稱全圖運行。

全腦多步長訓練與五類任務精度另列研究結果。長時間測試若因硬體不足受阻，必須保留精確指令、所需資源、預估來源與已完成的證據，不能把計畫中的數字寫成測量值。

## 18｜測試、驗收與證據要求

### 18.1 測試層次

數值單元測試檢查圖方向、聚合、梯度、時間動態、化學衰退、閾值、局部更新、CTC 與遮罩。整合測試檢查資料至輸出全流程。學習測試證明指定參數能改變並改善人工可解任務。真實資料與全腦測試檢查對實際來源的適用性。能力研究測試比較不同設定與對照組。

每項必要需求在第 23 章有可檢驗條件。機器可讀副本為 `requirements.json`。該檔初始狀態為 `specified`，表示有規格，不代表已實作。

### 18.2 必備數值測試

需有手算線性圖、隨機小圖對稠密參考、零邊／孤立節點／自我連線、不同 batch 與共享參數、前向多步、平滑模型有限差分、替代梯度公式、閾值訓練、延遲與不應期、正負與範圍限制、關閉調節等同基準，以及更新遮罩對動量與權重衰減的效果。

CTC 在極小字母表上枚舉所有路徑對照，包含連續重複字、空目標、不足長度、空白符號與 log-space 計算。無合法路徑時返回明確狀態，不能無聲把無限損失設為零。若提供這種特殊策略，必須顯式設定並計數。[S19]

### 18.3 核心確實學習的證明

人工延遲關聯範例要有訓練前後的保留資料成績、核心參數更新、凍結核心對照及破壞回饋對照。至少一個設定固定低容量外圍，只允許核心學習。未達標時先查輸入可達性、梯度、訊號尺度、狀態重設及答案洩漏，不能直接增加外部解碼器解決。

正式驗收前，agent 在不接觸測試集的條件下固定資料、seed、更新預算及門檻。能力門檻以可解的人工任務與預先登錄的基準為起點，不隨測試結果下降。真實任務不預先捏造 95% 等缺乏依據的保證。

### 18.4 韌性與安全測試

涵蓋損壞資料、超大形狀、大整數、錯誤 dtype、非法路徑、重複 ID、版本不相容、壓縮炸彈、磁碟滿、下載中斷、裝置離線、數值 NaN／Inf、教師逾時、取消、未完成快照與重新啟動。

使用假 HTTP 伺服器驗證教師重試、去重與錯誤，但不得把測試伺服器通過記成真實服務已驗證。測試不得要求網路金鑰或自動花費。

### 18.5 自動檢查

至少執行格式、編譯、`go test ./...`、適用套件的 `-race`、`go vet`、相依性檢查及可重現基準。競態模式若因裝置函式庫限制不能執行，要將 CPU 及裝置測試分開，不能整個略過。

另外檢查所有公開範例、CLI help、設定 schema、文件程式碼、匯出匯入、來源與授權、機制引用及聲稱的能力清單。版本報告需包含 Go、OS、CPU／GPU、Insyra 提交、編譯設定與隨機設定。

### 18.6 完成狀態

允許的狀態為 `specified`、`implemented_unverified`、`passed`、`failed`、`blocked_hardware`、`blocked_data`、`blocked_permission`。沒有證據路徑不能標示 `passed`。一般硬體不適用的條件需記錄理由，但不能用 `not_applicable` 把整項使用者需求移除。

「完整完成」表示所有必要交付已實作，必要參考測試與真實整合證據齊備，受條件限制的測試狀態已清楚揭露。若任一必要工作仍受阻或失敗，報告應使用「部分完成」及精確範圍，不包裝成全部完成。

### 19.3 必要例子

必備例子包括：人工圖訊號傳播、真實子圖載入、全腦前向／訓練檢查、延遲關聯、可訓練閾值、局部塑性、化學衰退與受體干預、先學 A 再學 B、離線教師蒸餾、學生離線評估、五類任務各一個完整流程、共同核心的多模態訓練，以及快照中斷恢復。

基本例子應不需金鑰，且不依賴未公開資料。需要下載的例子要先印出來源、大小、授權與操作，不在普通單元測試中下載大型資料。

### 19.4 模型卡與實驗卡

每份可散布的模型至少包含：使用資料與用途限制、資料集／拓撲指紋、模式、參數量與分類、外部模型、訓練範圍、已測語言／任務／解析度、評估方法、限制、已知失敗、硬體與再現指令。

未訓練模型可以發布為初始化模型，但不得使用訓練完成名稱。人工圖與真實圖的模型名稱必須可辨識。生成影音不得包含來源不明或授權不足的素材。

若懷疑固定真實接線無法勝過對照組，仍應完成框架與比較，不能讓程式強制真實圖勝出。研究結論可以是優勢不成立，而軟體仍能正確完成實驗。

## 21｜主要失敗情境與處理方式

| 風險 | 嚴重度 | 具體處理 |
|---|---|---|
| 分段、神經元、突觸接點、配對與參數數量混用。 | 高 | 每次匯入列出各種數量與篩選規則，模型與報告使用不同欄位。 |
| 全圖使用稠密矩陣或保存全部邊狀態歷史。 | 高 | 在啟動前估算，稀疏運算、有限回推、重算；不足時拒絕，不暗中裁圖。 |
| 外加編碼器、教師或控制器替核心完成任務。 | 高 | 禁止未宣告旁路，拆分參數與容量，重新訓練對照及教師移除測試。 |
| 只要 loss 下降就認為核心學會。 | 高 | 檢查核心梯度與更新，固定外圍實驗，以及未見資料的成績。 |
| 新經驗洗掉舊能力或測試資料進入重播。 | 高 | 保留學習矩陣、顯式生命週期與資料隔離，測試預算固定。 |
| 獎勵被重新命名成荷爾蒙，沒有時間或接收端差異。 | 高 | 強制來源／狀態／作用三層，干預測試與人工／生物命名分離。 |
| 閾值、增益與權重互相抵銷，無法知道學到了什麼。 | 中高 | 固定尺度參考、分組啟用可訓練參數，報告參數變化與同效解風險。 |
| 活動穩定懲罰讓模型靠沉默取得低損失。 | 中高 | 同時檢查任務成績、沉默率與輸出有效率，保留未加懲罰對照。 |
| 不同使用者共用快速權重或化學狀態。 | 高 | 不可變基礎模型與獨立個體狀態，競態與隔離測試。 |
| 回算、重試或恢復時重複學習與付費。 | 高 | 更新交易 ID、教師請求去重、純重算路徑與原子快照。 |
| 硬閾值有限差分失敗後錯誤修改替代梯度。 | 高 | 分開測硬事件時序與宣告的反向近似，平滑模型另測真實梯度。 |
| 程式依據過期套件 API、來源資料更新或未核對論文。 | 高 | 鎖定提交、版本與來源，更新必跑相容性與科學主張檢查。 |
| 無法取得受體或生物動態量測資料。 | 中高 | 未知保持未知，使用人工機制並標記，保留待校準與干預需求。 |
| 硬體、資料授權或金鑰阻礙完整驗收。 | 高 | 明示受阻條件，完成獨立部分，禁止以替代資料聲稱原需求完成。 |

### 21.1 不確定性不是空白授權

硬體規格、外部教師服務、公開授權與訓練預算未被本文件假定為已確認。安全預設是本機、離線、CPU 參考、不可覆寫、零雲端費用與小型測試。這些是起始安全條件，不是允許縮減最終需求的理由。

### 21.2 發現更好方法時

不影響公開行為、資料語意與授權的低風險實作優化可自行決定並記錄。改用別的主要框架、放棄真實核心、讓外部模型直接作答、刪除某模態、修改固定接線的主研究方向或破壞相容性，都需回問。

## 22｜交接流程與完成報告

### 22.1 接手 agent 的起手式

先讀本文件與第 23 章需求。檢查工作目錄是否已有檔案與有效 AGENTS 規則，保留原內容，不因「從零」就刪除現有資料。核對 Insyra 的指定版本、公開 API 與環境，再建立實作決策紀錄與需求追蹤。

具體架構與順序由 agent 制定。提出會影響範圍或授權的差異後才執行，例行命名、測試與內部拆分不用逐項回問。不能因為本文件有長期研究目標就停在討論；真正開始實作後，要逐項產生可執行成果。

### 22.2 乾淨環境的驗收路徑

在新的本機工作副本中，安裝已鎖定依賴，執行 doctor、單元測試與數值測試。運行人工延遲關聯、閾值訓練、調節干預、教師離線與快照恢復。再對官方來源執行真實子圖與全圖檢查，完成五類任務及共同核心流程，最後產生對照、效能與完成報告。

所有測試可分多次執行，但每次須有同一套可追查設定。離線小測試通過後，不會自動使全圖、真實資料、GPU 或外部服務測試通過。

### 22.3 最終報告必備內容

最終報告必須列出 repo 提交、依賴鎖定、需求逐項狀態、實際執行命令、完整／失敗／受阻測試、資料與模型指紋、硬體環境、數值結果、五類任務成果、持續學習矩陣、對照結果、生物機制證據等級、來源授權與已知限制。

每個 `passed` 需求有證據路徑；每個受阻需求有原因、精確未完成範圍及解除條件。不得以「已實作，應該可用」「已建立目錄」「待使用者自行測試」代替要求的驗證。

### 22.4 發布前另行確認

## 25｜接手用詞與最後檢查

| 用詞 | 本文件中的意思 |
|---|---|
| connectome／接線圖 | 神經元與實際連線的資料，不含完整生理運作。 |
| 拓撲 | 哪些節點相連及方向；與連線強度不同。 |
| 神經動態 | 狀態隨時間與輸入如何改變的規則。 |
| 可塑性 | 經驗如何改變連線或細胞本身的反應。 |
| 梯度／反向計算 | 計算輸出錯誤對參數變動的敏感程度，以便調整參數。 |
| BPTT | 沿前面時間步回推影響的訓練方式。 |
| truncation／有限回推 | 只追溯有限步數的影響，不一定清除目前狀態。 |
| surrogate gradient／替代梯度 | 為離散放電指定可用於訓練的反向近似。 |
| eligibility trace／近期參與紀錄 | 為近期活動相關的連線保留暫時紀錄，供之後回饋使用。 |
| homeostasis／活動穩定 | 在此框架指避免長期過強或沉默的受限調整，不代表完整生理健康。 |
| modulator／調節器 | 產生或施加改變神經反應與學習條件的機制。 |
| receptor／受體 | 生物細胞接受化學訊號的機制；人工敏感度係數僅是模型化。 |
| FiLM | 用條件訊號調整主網路活動的放大、縮小與偏移。 |
| 蒸餾 | 用老師的答案、機率或表示訓練學生，不是逐一搬移參數。 |
| CTC | 對沒有逐時間標籤的輸入序列，計算可能對齊並學習文字輸出。 |
| PPO | 利用行動結果更新策略的一種強化學習算法。 |
| checkpoint／快照 | 可恢復的保存物；完整訓練需要比權重更多的狀態。 |
| schema／格式規則 | 檔案或 API 的必要欄位、型別與驗證規則。 |
| adapter／轉接器 | 將外部資料、模型或服務轉成框架契約的實作。 |
| ablation／消融 | 移除或改變某機制，觀察它對結果的貢獻。 |
| profile／執行設定組 | 指定資料規模、裝置與其他限制的可重現設定。 |
| burn-in／狀態暖機 | 在正式評分或回推前用前綴資料重建需要的遞迴狀態。 |
| readout／讀出器 | 將選定核心活動轉成任務輸出的部分。 |
| model card／模型卡 | 說明模型資料、設定、已測能力、來源、限制與用途的文件。 |
