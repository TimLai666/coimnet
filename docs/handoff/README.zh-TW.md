# CoImNet 完整實作交接包

版本：1.0　｜　查核日期：2026-09-11

本交接包將 CoImNet 的目標、已確認決策、實作要求、研究依據與驗收方式整理成獨立文件。對象是沒有讀過原始對話的 AI agent 或工程團隊。

## 使用方式

解壓縮後，請 agent 先閱讀 `AGENT_START_HERE.zh-TW.md`，再完整閱讀主規格。只交付主規格 Markdown 也能理解全部必要內容，其他檔案提供導航、機器追蹤或閱讀便利。

| 檔案 | 用途 |
|---|---|
| `AGENT_START_HERE.zh-TW.md` | 接手入口、權限界線，以及可直接使用的執行指令。 |
| `CoImNet_Implementation_Plan.zh-TW.md` | 主要規格。25 章、85 項必要驗收需求、14 個工作包與完整來源。 |
| `CoImNet_Implementation_Plan.zh-TW.pdf` | 同一規格的閱讀版，包含章節目錄與頁碼。 |
| `requirements.json` | 85 項需求、角色、驗收條件、對應章節、工作包與所需證據。 |
| `sources.json` | 22 項第一手來源、查核範圍與限制。 |
| `VALIDATION.json` | 這次交接文件的結構、引用、清單及 PDF 檢查結果。不是未來軟體的測試成績。 |
| `SHA256SUMS.txt` | 本交接包各交付檔案的 SHA-256，供核對完整性。 |

## 這次已完成與尚未執行的工作

已完成的是企劃、依賴與資料來源查核、必要需求清單，以及文件格式檢查。沒有建立 CoImNet repo，沒有修改 Insyra，沒有訓練模型，也沒有測試全腦效能或五類任務成績。

需求檔中的 `specified` 代表規格已定義。接手 agent 必須以實際證據將需求更新成通過、失敗或受阻，不得整批改成完成。主規格列出的 CLI、schema 與範例都是待實作的目標契約，不是已有功能。

## 範圍與研究界線

完整目標涵蓋真實接線、可訓練神經動態與閾值、自訂訊號、持續學習、LLM 蒸餾、化學調節、五類任務、多模態共同核心、全腦與 GPU 驗證、保存恢復、SDK／CLI、測試及文件。是否優於一般模型、是否能達到商用語言或影音品質，需要真實實驗，不能由企劃書保證。

這次引用的研究與程式碼各有明示查核範圍。未有資料支持的荷爾蒙方程式、受體參數與神經分工，標為人工假設，不冒充已量測的果蠅生理。
