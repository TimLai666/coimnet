# CoImNet｜Agent 接手入口

版本：1.0　｜　日期：2026-09-11

## 任務

在使用者授權的本機工作目錄中，從零建立 **CoImNet（Connectome-Imprinted Network）** 的完整 Go 儲存庫。使用 `HazelnutParadise/insyra` 作為指定基礎，依《CoImNet 完整實作企劃書》建立可訓練的真實果蠅接線框架。接手不需要原始對話。

**這個交接包只有規格與查核資料，不含已完成的 CoImNet 程式、模型權重或訓練結果。** 使用者把交接包交給 agent，不會自動授權公開發布、付費或改動其他儲存庫。

## 先讀什麼

先完整閱讀 `CoImNet_Implementation_Plan.zh-TW.md`。它是主要規格，包含背景、功能、資料契約、機制、限制、測試、研究依據及決策紀錄。PDF 是同一規格的閱讀版。

再將 `requirements.json` 的 85 項必要需求匯入追蹤紀錄。初始 `specified` 只表示需求已定義，不能當成開發或測試已完成。`sources.json` 是 22 項來源的索引，保留了查核範圍與適用限制。

核對本機工作目錄既有內容、適用的 AGENTS 規則、Go 環境，以及 Insyra 的指定基線提交。不要因為指令含有「從零」就刪除已有內容。

## 完整交付不可刪掉的範圍

真實 MaleCNS 與 FlyWire 資料匯入、自訂訊號、連續與脈衝動態、可訓練閾值、稀疏前向與反向、跨時間訓練、局部可塑性、持續學習、化學調節、教師與蒸餾、模型與完整狀態保存，全部屬必要範圍。

五類任務為 OCR、語音轉文字、語言生成、文字轉影音、空間與導航。每類都要有可執行的訓練、推論、評估與失敗處理，並完成共用核心的多模態訓練及對照。小型例子只是其中一層驗證，不會取代真實資料、全腦與裝置驗證。

只完成目錄、介面、固定假輸出、README 或外部大型模型的轉接，不算完成核心能力。Insyra 不得只用來讀 CSV，主要運算與學習整合必須符合主規格。

## 可自行決定與必須回問的界線

可以自行決定：內部架構、檔案與套件拆分、實作順序、數值演算法、測試工具，以及授權工作目錄內必要的程式修改。決策與理由須寫入 repo。

必須先確認：改換主要框架或資料來源、縮減必要功能、推送上游 Insyra、遠端 repo 建立或發布、破壞既有相容性、刪除原始資料、外傳非公開資料、付費與超出預算，以及選定對外發布授權。

缺少 GPU、資料存取或付費授權時，記錄精確受阻範圍並繼續獨立工作。不能默默換小圖或外部模型，也不能把受阻當成已通過。

## 實作與驗證紀律

每項完成需求都應連到實際程式、文件、重現命令、環境、輸入指紋、測試日誌與觀察結果。神經數值測試要有手算或獨立參考。快照測試要真正重新啟動程序。教師移除測試要真正關閉教師及網路存取。

軟體通過測試、任務能力得到證明、生物機制符合實驗，是三種不同結論。人工調節器不能只因損失下降就命名成真實荷爾蒙模型。資料集的分段、神經元、突觸接點、配對連線與參數數量要分開報告。

最終交付需有需求逐項狀態、實際執行過的測試、五類任務成果、持續學習矩陣、對照、資源量測、來源授權及所有受阻事項。未完成項目不得以「應該可用」結案。

上述指令只在使用者明確指定或授權工作目錄後開始本機實作，不建立任何額外的付費或發布授權。
