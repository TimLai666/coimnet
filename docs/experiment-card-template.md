# 實驗卡（範本）

每個可重現的執行或比較矩陣（訓練、模擬、空模型對照、可在異地重跑）都附一張實驗卡，任務、規格與日期寫入日期。填寫時逐欄查證，不寫無法從檔案或證據核對的內容。實驗卡不取代模型卡：實驗卡描述這次執行的過程與結果，模型卡描述被產出或使用的模型。

## 名稱

- 值：______________

**命名規則（必填，以下都是必要欄位的規則，不是選項）**：
- 未訓練以 `initialized-` 開頭。
- 人工圖以 `fixture-` 開頭。
- 真實子圖以 `real-subgraph-` 開頭。
- 完整真實圖以 `male-full-` 開頭。
- 名稱一次只能使用一個前綴，可另外附任務或設定向的名稱。
