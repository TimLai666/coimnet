# itemMSE 的實作格子

Root 已閱讀兩份測試。原始一般建置實際得到12 fail／4 pass，失敗對應三個可表示的極大值、極小平方、真正超限與三條公開錯誤傳遞；一般數值、寬度及禁止回饋控制通過。race 紅測試同樣必須完成才採用實作。

可改動的正式位置只有 experiment/adaptive_run.go 的標準庫 import 與 itemMSE 函式。候選放 runs/.tmp/mse-report-20261016/implementation.go.txt，包含該檔完整內容。簽名、寬度錯誤及原有呼叫端保持。

逐項計算原始 d，若 d 非有限回0與包含item.ID的錯誤。保留 mse += d*d 原運算式，另外統計 d 非零且平方小於0x1p-1022的數量。若 mse 有限，且沒有這種平方或 mse >= tinyCount*0x1p-1022，就沿用原來除以寬度的結果。

只有中間溢位或上述主導結果的極小平方，才用重用的 big.Rat 累加每個相同float64 d的精確平方，再除以寬度，最後只轉換一次float64。最終值非有限就回0與包含item.ID的錯誤。這是同一個平均，不新增截斷或任意上限。

不得修改測試。保留其他程式、公開文件、格式、正常路徑、重設、權限及狀態提交。不要新增空輸出或並行修改輸入的支援契約。Root用凍結測試與原始來源指紋先驗候選，再決定是否採用。
