# 生物啟發設定的數值審查

Scope: CLEAN。Root 審查 `experiment/bioinspired.go` 的兩個判斷、完整 `bioinspired_finite_test.go`，以及相關公開執行入口與報告。

沒有尚待修正的已確認缺陷。NPF 的 Suppressed 使用正向區間判斷，NaN 與正負無限大無法通過。Tolerance 先要求正值，再拒絕無限大。兩者沿用原錯誤位置、文字及優先順序。

八個新頂層測試涵蓋 Validate、公開 Run、非法值的空報告、Ecdysone 原條件、有限邊界、合法 JSON、錯誤順序及 context。Root 親自執行修正前與修正後驗證，舊版的三個頂層回歸失敗，修正後與九個既有控制共 17 個頂層測試通過。沒有修改凍結測試來通過驗證。

七份完整合法報告在修正前及兩個新的修正後程序中逐位元組相同，包含最小正數、最大有限 Tolerance 與 Ecdysone 控制。原始三份 JSON、探測程式及指紋保存在本資料夾。

這次只完成工程修正。模型、學習目標、既有歷史證據與生物假設保持。生物啟發報告的可變設定共用問題仍由另票處理。
