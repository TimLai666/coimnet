## Root 骨架與期待

`l2Norm([]float64) float64` 的輸入來自已驗證的快速狀態，非負 Euclidean norm 依 float64 捨入回報。正常範圍維持原本按索引的平方加總與開根號位元結果。中間平方溢位或下溢造成的錯誤結果，使用穩定計算；真正無法回報有限幅度時，由既有 Run 的 checkFinite 拒絕，神經／快速狀態不提交。空／全零回報 0，符號不影響幅度，不限制合法 plastic_max，不新增模型欄位、版本或依賴。

正式來源僅 `simulate/plasticity.go` 的幅度函式及註解，必要時同步 `simulate/runner.go` 的幅度拒絕註解。Root 擁有 `simulate/plastic_norm_test.go` 的永久公開測試、期待、正式修正與驗證。`simulate/plasticity_test.go` 只允許修正已有獨立數值證據否定的 TestPlasticL2OverflowIsRefused，保存完整原件及舊測試執行結果，其餘原文保持。

公開流程：Build → RestorePlasticState → Run → State／PlasticState／report。三個合法核心／規則組合（continuous/hebbian、LIF/hebbian、LIF/stdp），凍結／可學習、零／單值／雙值、正負、1e200、1e-200、平方為非零 subnormal 的 1e-160、次正規狀態、正常混合極小值、接近 float64 上界與真正上界之外。純量幅度以 abs 手算，雙值與數值檢查以 math/big 256-bit 平方和開根號獨立參考。真正溢位必須仍以 plastic l2 回錯、回傳空報告、兩種狀態與輸入不變；用非零脈衝保證候選神經狀態原本會變。

原有錯誤期待的 Root 判斷：兩條邊、plastic_max 1e200 時，快速狀態幅度上界 sqrt(2)*1e200 是有限數，所以原測試的「norm 無法表示」期待錯誤。永久測試保留其真的超出有限幅度的拒絕目的，新增回歸保留原先大閘門學習流程的正確成功與有限報告。

普通模型的合法源碼前後與新程序對照要比較 Protocol／hash、參數、完整神經快照、快速狀態與完整報告，不排除欄位。全部現有來源與測試先固定指紋；原測試修正前後須有 Root 裁決與唯一函式差異。

## 數值檢查

不把 math.Hypot 的單次逐項結果當成唯一精度證據。需要檢查平方落在 subnormal／零時的誤差、許多小值加上一個較大值、接近上界的捨入，以及普通值加極小尾項的歷史位元相容。最小實作先保留可靠的舊路徑，再對實際失敗情形修正，避免全域改用會改變正常位元的另一種加總。
