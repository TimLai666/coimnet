## 驗證範圍

沿用既有官方 KMNIST 的六份檔案與原匯入 metadata，6,000 張平衡訓練圖片、200 張 development、2,000 張主要測試及 2,000 張確認測試。這些切分先前已觀察，沒有當成全新盲測。模型是人工 52 節點、1,248 邊的連續核心，保存 23,568 項參數，其中 23,516 項宣告可更新，52 項時間常數凍結。化學控制器及反應係數固定，沒有增加可訓練化學參數。

六個跨建置配對的所有參數、最佳化器陣列、完整快照、20 輪訓練損失與 development 評分相同。同圖片的分類錯誤互換為零，完整載入後的下一次更新也相同。Root 另從原始圖片標籤核對 288 份評分與混淆矩陣，並獨立比對每份快照的八個參數／最佳化器數值欄位。原模型及訓練來源保持。

完整一般／競態各 58 套件通過，5,778／5,777 個測試事件成功、22／23 個略過、0 個失敗。build、vet、固定相依性及格式檢查通過。原沙箱的本機連接埠失敗保留，沒有略過該測試解決限制。完整工程日誌以 gzip 保存，解壓後與回條中的原始 SHA-256 相同。

本輪修正的是 Root 驗收與分析工具：合法類別 0、失敗回條／變更日誌、Go 負零、固定切分與完成條件，以及距離的平方下溢／溢位。原失敗與修改前來源保留。穩定距離修正沒有改變本次實際模型的距離報告，六個配對均為零差異。正式 Go、公開 API、模型格式及依賴沒有改動。
