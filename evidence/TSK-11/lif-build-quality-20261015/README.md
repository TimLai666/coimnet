## 一般與競態建置的差異

相同種子、同一化學設定下，六組最終參數與下一次更新都沒有逐位相同。主要測試辨識率差介於 −1.30～+0.80 個百分點，確認分割的差異介於 −1.35～+2.15 個百分點。這些是跨建置的實際觀察，不當成逐位重現成功，也不只憑差異就判定新的演算法缺陷。

每組模型在自己的建置中保存，再由新程序載入，完整參數、最佳化器、後續評分與下一次更新摘要都相同，共 12／12 組。訓練日誌的初始活動量與載入後的活動量對應不同時點，不能宣稱整份日誌相同。

## 範圍與證據

本研究使用 KMNIST 十類日文手寫單字元、6,000 張訓練圖、三個固定種子及兩個各 2,000 張的固定測試分割。資料先前已觀察過，不是新的盲測。模型是 52 個節點、1,248 條邊的人工接線 LIF 網路，化學受體與係數是明示的工程假設，結果不外推到真實全腦或實測生物機制。

Root 以另一份標準函式庫程式重建原始標籤、核對 288 份逐筆預測的樣本數、正確數、辨識率與混淆矩陣，並核對六組跨建置配對各九份數值陣列，見 [Root 驗收](root-final-audit.json)。完整化學初始設定的 12 組核對見 [化學設定驗收](chemical-state-audit-root-final.json)。保存的初始化學狀態不是每次執行中化學軌跡的量測。

分類損失由固定的 Go 目標函式計算，已檢查有限值及配對差，沒有逐張輸出值供獨立重算分類損失。原始流程、輸入指紋、全部曲線與保存摘要分別見 [protocol.json](protocol.json)、[analysis-input-lock.json](analysis-input-lock.json)、[training-complete.json](training-complete.json) 及 [完整比較](quality-and-state-comparison.json)。

減法審查：沿用固定種子與預算，保留全部結果，不因這次結果新增參數搜尋或選擇較好的輪次。
