2. P2 current-row raw stimulus loss at a shuffled block boundary: CLOSED.
   Previous rollout.go behavior zeroed rawStimulusBlocks[absoluteIndex%16] after every generated step, including step zero. The final code at rollout.go:359 only clears generated rows when stepIndex > 0, preserving the recorded current row. The regression at rollout_test.go:244 supplies a positive raw current row at the boundary and compares the shuffled trace with the causal expected input sequence. No remaining P2 was confirmed in this fix path.
