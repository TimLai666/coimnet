# 34 — 使用者可以比較含刺激歷史的軌跡模型與無記憶控制組

Epic：TSK-11 真實任務資料

User Story：使用者可以知道模型是否利用搬移前已發生的刺激與移動歷史，而不是只延續上一個方向。

Blocked by：無。方法已核准，推論隔離已由 ticket 33 驗收。

Status：in_progress（2026-10-03）。使用者在方法說明後要求「繼續」，核准位置與已發生刺激的工程代理。

## Root 方法決策（2026-10-03，使用者已核准）

保留現有 `realnav` v1 範例，另做以觀察位置與已發生刺激為輸入的工程代理模型。第一個切片是完整試次的刺激記憶與模仿學習，使用真實記錄的下一步位移作標籤，再以自主行走及控制組評估。這個方案能檢查刺激歷史是否改善回到評分區的結果。資料沒有可靠感覺或控制命令，因此驗收只適用於這個明示輸入的工程模型。

沿用已授權來源，以工程模型驗收。結果不能用來宣稱重現果蠅神經機制。

## 已確認的資料與缺口

固定來源 SHA-256 為 `83e13b7057957cf41a45dc91996a4519be7066519242b6912c65b2418cb91670`。主 agent 重讀全部 231,130 列、39 試次，五個區段及逐試次遞增的時間見 [本輪來源檢查](../../evidence/TSK-11/inference-isolation-20261003/navigation-source-check.json)。

[作者固定版本 README](https://github.com/strawlab/titova_et_al_displacement_supplemental/blob/0eb07940a9ffdedd97ada81f75e9d5f7bface579/README.md) 說明：rewarded 組的 LED 提供光遺傳刺激，non-rewarded 組拔除 LED，但仍保存預定亮燈時間。`slope` 無法可靠估計朝向。`estimated_food_x/y_cm` 保存實際或假想目標位置。資料沒有神經獎勵到達時間、感覺觀察或動作指令。

現有 [資料與因果契約](../../examples/realnav/README.md#data-and-causal-contract) 只使用搬移後的位置及上一位移，排除刺激歷史，並每 256 個樣本重設神經狀態。新模型必須有獨立特徵版本及快照驗證，避免改變合法 v1 快照的行為。

## 最小切片與驗收

1. 來源 → 分割：固定原 13 個 test 試次，只從原 26 個 train 試次事前切出 validation。保存實際清單、分層規則與指紋，再選訓練設定。三組互斥、完整覆蓋；禁止拿 test 選參數或排除失敗。
2. 過去紀錄 → 模型：目前位置、上一位移與時間差沿用觀察代理。刺激只按過去列推導：rewarded 且 LED 正值標為 delivered stimulus，non-rewarded 正值另標為 scheduled-only metadata，兩者不能混成 reward。模型只接收 delivered stimulus 歷史。把儀器記錄時間當成工程觀察時間是明示假設，神經獎勵到達時間保持未知。ID、condition、segment、搬移量及目標位置不成為輸入特徵。
3. 歷史 → 學習：同試次從零狀態開始，保留刺激前後的神經狀態，搬移期間的狀態處理須先固定為工程假設。用搬移後的下一位移作模仿標籤，梯度不得在歷史與標籤之間中斷。不能沿用 256 步重設後宣稱有跨區段記憶，也不能把觀測位移當成動物控制命令。
4. 凍結模型 → 評估：目標位置由 evaluator 單獨持有。自主行走沿用固定工程場地與門檻，同時報告模型、無刺激歷史、刺激歷史打亂、方向延續及隨機控制。可訓練模型控制組的初始化、參數容量、訓練預算與試次相符；訓練前後及所有失敗都保存，不預先承諾命中率。
5. 驗收與交付：先寫時間／未來資訊、刺激語意、試次污染與狀態連續性的失敗測試。確認未來目標或 metadata 改寫不影響既有模型輸入，再驗證資料匯入、訓練、新程序推論及自主評估。軟體通過和導航改善分開記錄，TSK-11 的整體驗收仍依 ticket 29。

失敗或部分資料：來源指紋錯誤、非有限值、非遞增時間、空／重複／未知試次與缺必要欄位都拒絕。刺激零值是已記錄的零，缺值保持未知並禁止產生虛構 reward。取消或輸出已存在時沿用現有排他寫入契約；先完成資料驗證再建立輸出。超出已宣告的 episode 或記憶體容量時回錯並報告，不能截斷歷史後繼續當成完整試次。

## 減法審查

沿用原資料授權、試次 ID、完整分割、CPU 核心、凍結推論及評分器。先移除「把 LED 正值直接當 reward」的假設，不新增未知回饋的假分數或新的強化學習演算法。新模型只放範例，原始資料與模型留在 Git 外。一般格式名稱及內部實作由 root 在方法核准後定案，不另要求使用者決定。

## 實作契約與分工（2026-10-03）

新範例位於 `examples/realnavmemory`，不更改既有 `realnav` 的特徵或快照。新增 `trajectory.ReadWithStimulusHistory` 在同一次通過指紋的 CSV 解析中回傳逐列刺激紀錄，原 `Dataset` 與 `Point` 保持不變。缺少或非法 LED、未知或試次內變動的 condition 都拒絕。預定事件只留在資料稽核。

- 完整試次从第一列開始，原始順序不排序、不截斷，每列是一個 `model_step`。核心狀態跨全部五區段保留，搬移列照觀察位置推進但沒有直接損失。區段切換、上一時間差大於 0.5 秒或位移大於 5 cm 時，上一位移特徵設為零，仍保留目前位置、實際上一時間差與整段狀態。這是工程假設，不是動物動作或生理時鐘。
- 六個固定特徵為目前 x/30、y/30、上一 dx/2、dy/2、上一 dt 秒與當下已記錄 delivered stimulus 的 0/1。第一列上一位移及 dt 為零。標籤只在搬移後、同區段合法相鄰三列建立，以下一位移 cm 作答案。目標區中心只進評分器。
- 每試次最多 16,384 列，超過即拒絕。八個連續節點、64 條有向邊含自環、6→8 encoder、8→2 readout。DT=1、tanh，初始 tau 依序為 2、4、8、16、64、256、1024、4096 model_step。初始化權重幅度 0.02、encoder 0.2、readout 零。用完整 `PredictAll` 與帶遮罩 MSE upstream 呼叫 `StepFrom`，Truncation=0。不新增訓練器。
- 可訓練組為 delivered、no_stimulus、shuffled_stimulus。後者採 16 列區塊延遲的因果置換，只在下一區塊輸出前一完整區塊的固定種子 Fisher–Yates 刺激序列，首區塊為零。最後未輸出的刺激不補到過去。這同時改變刺激時機與位置關聯，不能單獨歸因於純置換。自主行走中實際刺激固定零，控制組依同一因果規則處理。
- 原 13 test 清單固定。原 26 train 按 condition 分層，validation 共 6 個，以最大餘數分配名額，層內按 SHA-256(`20261003` + 分隔符 + trial ID) 排序選取，其餘 20 個訓練。先存實際清單與指紋，三組完整互斥。這 13 個試次先前已評估，不是從未看過的新測試集。
- 事前設定：seed 20261003、20261004、20261005，各 10 epoch，每 epoch 每個完整訓練試次一次更新。LR=0.001、ClipNorm=1，全部參數可學，無衰減、無梯度截斷。三組相同初始化、容量、順序與 200 次更新。validation 只報成績，本切片不據其結果更改設定。方向延續與隨機位移使用訓練標籤的平均位移長度。
- 自主評估以最早合法搬移後相鄰列對初始化，先重播到起始觀察以前的完整歷史。後續位置與上一位移由模型行走產生。固定半徑 30 cm 工程場地、2 cm 命中半徑、200 決策步、每步 dt 特徵 0.1 秒，不轉成動物時間。參數與 optimizer 凍結。

共用資料型別：`historyStep{Input [6]float64, Target [2]float64, Scored bool, T float64}`，`historyTrial{ID string, Condition string, Steps []historyStep, RolloutIndex int}`，`trialSplit{Train []string, Validation []string, Test []string}`。輸入陣列與標籤分開，RolloutIndex 是第一個合法搬移後觀察索引。模型使用從零开始的整試次及完整遮罩梯度，不以預算為理由切成 256 列。
