# 完整刺激歷史工程範例證據

這個切片比較固定八節點工程模型是否因刺激歷史改善位移預測與自主行走。資料是作者固定版本的真實果蠅軌跡，接線是人工圖，成績不能當作神經機制證據。

39 個試次保存全部 231,130 列。只用 rewarded 的 6,815 列實際刺激；non-rewarded 的 349 列預定事件不進模型。原 13 個測試試次保持不變，原訓練組事前分成 20 個訓練與 6 個驗證試次。驗證成績只回報，不選參數。

## 結果

九組模型各完成 200 次完整試次更新。測試 MSE 由 0.02002106 cm² 降至 0.01689731–0.01750598 cm²。刺激與無刺激的差異隨種子改變方向，尚不能證明刺激歷史帶來改善。

所有模型在訓練前後、三種控制與三個種子均為 0／13 命中。方向延續三個種子均為 0／13；隨機行走依序為 0／13、0／13、1／13。每組保留全部 13 個試次及每試次 200 個決策，沒有排除失敗。位移預測變好沒有轉成自主導航改善，TSK-11 仍未通過。

| 種子 | 有刺激歷史的測試 MSE | 無刺激的測試 MSE | 延遲打亂刺激的測試 MSE |
| --- | ---: | ---: | ---: |
| 20261003 | 0.01689731 | 0.01689997 | 0.01689742 |
| 20261004 | 0.01750426 | 0.01749876 | 0.01750598 |
| 20261005 | 0.01718010 | 0.01718637 | 0.01718016 |

單位為 cm²，訓練前各組均為 0.02002106 cm²。這是觀察式位移預測，不是自主導航分數。

## 核對資料

- `preregistration.json` 與 `preregistered-contract.md.txt`：訓練前獨立固定的清單、參數、來源指紋及當時契約。文字檔保留當時內容，包括歷史用字，指紋不再變更。
- `prepared-plan.json`、`prepare-validation.json`：實際 CLI 計畫及與預註冊、原快照清單的核對。
- `stimulus-history-probe.json`：公開 API 與舊 API 逐列一致、逐試次與區段刺激統計。probe 原始碼及實際命令另存，root 重跑與執行者回報逐位元組相同。
- `training-summary.json`：全部九組的訓練曲線、容量、更新次數、參數變動與指紋。全歷史梯度測試與初始失敗日誌保存於本目錄。
- `inference-report.json`：每組訓練前後三個分割的完整 MSE。
- `rollout-summary.json`：24 組的全部試次、命中、距離、碰撞與完整 trace 指紋。完整 trace 及模型留在記錄的 Git 外目錄。
- `commands.json`、`real-run-integrity.json`：四階段命令、退出碼、環境、時間及新程序重現。推論及自主評估各兩次逐位元組相同，原資料、舊模型與新 bundle 不變。
- `negative-plan-final.json`、`negative-bundle-final.json`：20 個最終版實際 CLI 錯誤、輸出排他與取消檢查。
- `initial-environment-test-failure.log`：最初把真實資料 opt-in 環境變數帶入全套測試，與 CLI 的嚴格配置解析衝突。正式全套移除該變數，真實匯入另以專項命令驗證。
- `cache-cleanup.json`：磁碟不足時僅清除這輪已停止使用的 Go 建置快取，來源、模型與日誌保留。

正式一般測試重新執行 57 個套件。完整 race 命令通過 57 個套件，其中 52 個由 Go 驗證來源與輸入後使用快取，5 個重新執行；3 個受影響套件另以 `-count=1` 重新執行 race。建置、vet、格式、模組校驗與 tidy diff 均通過。

最後審查補上「after 每個 optimizer step 都必須為 200」及起始列正刺激的因果延續。實際九組模型的 144 個 optimizer step 全部為 200，沒有 open accumulator。修正版再次各做兩次推論與自主評估，與修正前真實結果逐位元組相同。訓練器、模型、資料特徵與固定設定未變。

初次全新 race 全套因最後審查需要改碼而主動停止，日誌記為未完成。最終驗證保存獨立來源指紋，沒有把中止當成通過。

## 科學界線

位置是明示觀察代理，位移是模仿標籤，LED 是儀器事件。模型步不是動物時間，神經獎勵到達時間未知。目標中心只供評分；訓練沒有導航 reward。打亂控制同時改變刺激時機與位置關聯。原測試集先前已評估，不是全新未見資料。軟體驗收、任務學習與生物機制分別判斷。
