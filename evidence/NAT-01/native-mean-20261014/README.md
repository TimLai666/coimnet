# 原生平均與集合量測驗收

本輪修正兩項原生模擬可靠性缺陷：有限平均被中間加總溢位誤拒，以及成功發布無法 JSON 編碼的集合原始總和。正式改動只在共用 Runner，核心動態與模型格式保持。

- 永久回歸：原來源 8 個失敗事件，修正後 13 個事件通過。LIF 公開補驗原來源 3 個失敗，修正後一般與 race 各 3 個事件通過。
- 正常相容：16 組完整 Go JSON 位元組相同，舊狀態在新程序恢復後接續相同，沒有排除欄位。
- 完整工程：一般 58 套件、5,635 個通過事件、22 個既有跳過；race 58 套件、5,634 個通過事件、23 個既有跳過。格式、build、vet、固定相依性、CLI 保存接續及最後 11 項治理通過。
- 暫存清理：本輪 9,714 個普通檔案、41,797 個快取連結與 9,228 個目錄已清除，普通檔案總量 1,211,375,287 bytes。原有目錄及外部快取目標保留。

驗收範圍為 CPU 人工圖的公開機制與正常接續，不證明真實辨識率提升、完整圖的新量測、生物定量正確或絕對零 bug。MOD-04 的零化學作用增益缺陷仍待相容性決策，正式政策未改。

完整回條見 [verification.json](verification.json)、[Root 審查](root-review.md)、[正常比較](compatibility-comparison.json)、[清理](cleanup.json)及交付完成後的 [delivery.json](delivery.json)。[changed-files.md](changed-files.md) 列出每個實際變更檔案，原始診斷與修正版分別保留。

重現時先依 `cache-prepare.py.txt` 建立本輪專案內工作目錄，將保存的 `*.go.txt` 複製回 overlay 指定位置，再執行 `run-go.py.txt` 的各命令回條及 `engineering.py.txt`。原始與修正來源、測試指紋、環境和輸入都保留，清理後不存在的路徑是本輪暫存，不是必要原始資料。

減法審查：直接修復共用計算與發布入口，沒有增加使用者設定、報告表示法或依賴。
