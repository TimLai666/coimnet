# 中性化學增益修正

敏感度增益的上下限套用零值預設後，必須有限且包含 1，亦即 `0 < GammaMin <= 1 <= GammaMax`。`[1,1]` 合法。不符合規則的宣告與舊存檔會被拒絕，原檔不會被改寫。這項相容性變更已取得使用者授權，見 [authorization.json](authorization.json)。

原始來源的 20 個回歸失敗事件，在正式修正後改為 21 個通過事件。建構、前向、反向、宣告更換、恢復與存檔載入都經過同一個驗證入口，拒絕時保留原本的設定與狀態。

15 組合法舊個體，以及 10 組合法舊訓練存檔／模型包，在舊、新來源的獨立程序中載入後，後續模擬、預測、訓練結果及完整狀態的 Go JSON 位元組相同，所有控制都有實際參數更新。3 組不合法舊個體、10 組不合法舊訓練保存物正確拒絕，原始檔案保持。另有 3 組個體解碼拒絕。見 [compatibility.json](compatibility.json) 及 [persistence-endpoints.json](persistence-endpoints.json)。保存的小型人工存檔只作恢復證據，不是模型產品。

完整一般與競態測試各 58 個套件通過，一般 5,702 pass／22 skip，競態 5,701 pass／23 skip，沒有 fail。格式、建置、vet、固定相依性、公開 API 文件及 CLI 新程序接續也通過。CLI 的 80 步保存後接續 40 步，與不中斷的 120 步存檔完全相同。完整命令、環境、來源與測試指紋、跳過項目及日誌見 [verification.json](verification.json)。

這次驗證使用人工小圖。沒有新量測真實單字辨識率、全腦效能或生物定量反應，也不能由測試通過推論整個框架沒有 bug。最後治理、暫存清理與交付結果分別保存在 `governance.json`、`cleanup.json` 與 `delivery.json`。

減法審查：沿用共用驗證入口，不增加自動遷移、重複驗證器或任務個別補償。
