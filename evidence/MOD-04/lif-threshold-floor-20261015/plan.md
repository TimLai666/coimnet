# 化學門檻下限一致性

本輪沿用原有 `max(theta + shift, theta_min)` 投影公式。先用公開入口及精確有理數核對結果，再判斷先於投影的有限值檢查是否違反既有契約。`ThetaMin`、原門檻及輸入偏移都必須有限。正向溢位與明確非有限輸入繼續拒絕。

## 驗收里程碑

1. 重現一般與耦合路徑差異，核對主規格、ENG、ticket 21 與精確數值參考。
2. Root 審查並凍結失敗回歸，涵蓋 LIF、混合核心、重算及下限導數。
3. 最小候選通過回歸，正常控制與原始來源逐位一致。
4. 正式採用後完成格式、build、一般／race、vet、固定相依性與需求證據驗收。
5. 保存必要證據，清除本輪自有暫存，分開提交修正與測試證據，核對遠端。

## 骨架與責任

- `LIF.forwardLIFCoupled(ctx, p, initial, inputs, sequence, saved) (*LIFTrace, error)`：先完成既有下限投影，再判斷供放電使用的結果是否可表示。下限 flags 與反向歸零保持。
- `Mixed.forwardCoupled(ctx, p, initial, inputs, sequence) (*MixedTrace, error)`：LIF 節點採相同規則，連續節點拒絕非零門檻偏移的規則保持。
- 凍結測試使用既有序列替身；精確參考使用 `math/big.Rat`。測試作者只寫新測試，另一位作者只填兩個候選來源檔，Root 審查及執行驗收。

### 期望結果

- 有限負偏移相加超出 float64 負向範圍，但 max 投影結果為有限下限：LIF、混合核心及 LIF 重算正常回傳，輸出符合獨立參考與一般模擬。
- 候選電位恰等於下限時替代梯度非零，但對基礎門檻及偏移的梯度為零，證明確實經過投影。
- 有限值恰觸下限、一般負偏移、正偏移及中性偏移保持原行為。
- 正向溢位或明確 NaN／Inf 偏移回錯且不發布部分 trace。
- 正常參數、延遲、適應與慢速穩定控制在相同建置下逐位一致。
