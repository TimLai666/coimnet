# 混合核心完整化學計算對照

本階段只檢查 mixed continuous／LIF 完整歷史的化學訓練組合。來源依序讀上一列原始核心輸出、更新化學濃度、經區域傳輸與受體位置產生效果，再推進神經動態。讀出表現只影響讀出，不取代來源活動。完整梯度須抵達核心、輸入映射及原始輸入。

## 獨立參考契約

測試使用僅限測試的前向微分數值，逐一播種所有核心權重、bias、log_tau、theta_raw、encoder、readout 與輸入。獨立寫出已宣告的方程式，不呼叫 dynamics／modulation 的前向、反向、occupancy、effects、kinetics 或 controller 計算函式。framework 的 NewNetwork、PredictAll、LossGradientFrom 是受測入口。測試的硬事件值為 0／1，導數為 fast_sigmoid 的 psi。硬重設採停止事件導數，適應則保留事件導數。不應期保持 reset 電位且忽略本列驅動。若測試只用普通硬事件差分，驗收無效。

有界兩節點圖包含兩個跨類型方向與延遲、自迴路、非零初始化學濃度、兩區域非對稱運輸、與節點所在區域不同的顯式受體位置。分別使用活動控制器與神經活動來源。敏感度增益／偏移、LIF 閾值及 expression 均啟用。至少檢查完整反向、關閉化學、閾值下限／效果飽和與不應期。float64 核心與 Insyra float32 邊界分開計算，容差須有誤差理由，禁止為綠燈任意放寬。

## 失敗與範圍

| 情況 | 本票預期／驗證責任 |

| 真實任務品質與生理校準 | 本票未量測，不由數值通過推論 |
