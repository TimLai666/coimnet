# 替代梯度分母平方溢位驗收

有限分母約為 `1e155` 時，原本的平方會先溢位，讓可表示的局部斜率 `1e-310` 變成零。公開一節點案例的正負輸入都出現這個問題，應約為 `0.005` 的參數梯度被算成零。修正只恢復這項例外計算，正常算式與真正下溢保持。獨立 Python Fraction 參考與凍結回歸見[重現](reproduction-verification.json)、[參考](exact-reference.json)及[測試指紋](frozen-test.json)。

| 驗收 | 實際結果 |
|---|---|
| 修正前專項，一般／競態 | 各 17 個事件通過、34 個失敗，確實重現 |
| 修正後專項，一般／競態 | 各 51 個事件通過 |
| 完整一般測試 | 6,114 個事件通過、22 個略過，零失敗 |
| 完整競態測試 | 6,113 個事件通過、23 個略過，零失敗 |
| 套件結果，一般／競態 | 各 58 個通過、3 個略過 |
| 原有結果 | 各 6,085 個終端事件保持相同，只新增本票 51 個通過 |
| 正常與舊保存對照 | 32 份正常紀錄、32 次神經狀態接續及 12 次化學模型接續相同 |
| 其他工程檢查 | 格式、建置、靜態檢查、模組校驗、固定 Insyra v0.3.4 及最後 31 項治理通過 |

完整命令、環境、輸入指紋及日誌見[工程驗收](verification.json)。你核准的「增益範圍必須包含 1」拒絕與合法範圍控制，也在兩種完整建置中通過。
