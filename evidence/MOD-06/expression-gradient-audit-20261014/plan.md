# 記憶讀出調節的梯度稽核

延續「確保沒有任何 bug」的完整目標。本輪核對讀出增益、受體區域平均與活動來源回授在同一條訓練路徑中的組合。目前來源已要求讀出範圍包含 1，不能把上一輪敏感度缺陷直接套用到這裡。

Root 驗證骨架：使用公開 PredictAll／LossGradientFrom 與既有獨立前向微分參考，核對多個讀出節點、不同區域的受體、正／負／零 Scale、增益夾限及固定截斷視窗。控制器與神經來源各自驗證。另保留刻意移除平均除數、讀出種子或夾限導數的反例，確認參考會辨認錯誤。

正式程式及既有測試先保持。診斷檔只放本輪 runs/.tmp/，參考來源與程式指紋保存於本證據目錄。只有實跑差異與來源追蹤一致時才判為 bug，先寫公開失敗測試並由 Root 凍結後才實作。涉及模型相容性或已確認機制的變更，依 AGENTS.md 取得決策。

四項本輪里程碑：共用契約與獨立審查；有非零與錯誤控制的實際梯度核對；必要修正及相稱驗證；證據、暫存清理、提交與遠端讀回。這四項不是完整零 bug 目標的分母，也不把小圖通過當作真實品質或生物校準證明。

減法審查：沿用既有獨立參考與公共入口，不新增正式驗證器或改寫正常算式。未定義的公開控制器宣告更換契約留在原 Follow-ups，沒有新證據時不重複同一輪推論。
