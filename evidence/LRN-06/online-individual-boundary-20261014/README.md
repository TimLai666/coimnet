# 線上作答與訓練的共享狀態修正

同一個體同時有線上學習與外部訓練時，舊實作有兩個會影響學習的狀態錯接。本票修正兩個高階操作的鎖定範圍，保留公開 API、模型保存格式與訓練算式。

| 問題 | 舊實作的影響 | 修正後 |
| --- | --- | --- |
| 作答後再取得模型版本 | 外部訓練插入時，答案使用舊參數，紀錄卻標成新參數 | 參數版本與作答共用一次個體鎖定 |
| 回饋先預測再另外訓練 | 外部訓練插入時，加權 target 使用舊預測，梯度使用新參數。零分回饋也可能產生新梯度 | 預測、target 加權與訓練共用一次個體鎖定 |

原始公開插入診斷見[前一階段證據](../online-boundaries-20261014/public-interleave-v3-diagnostic.json)。正式回歸先在舊實作重現 17 個行為失敗，三個錯誤／取消控制通過，再凍結測試修正。修正後 5 個頂層回歸、31 個測試事件通過，race 連續 20 次共 620 個事件通過。化學、凍結、累積、既有 Adam 動量與等待取消都包含在控制中。

[工程驗收](verification.json)記錄完整命令、環境、來源指紋及日誌。完整一般／race 各 58 個套件通過，分別有 5,152／5,151 個測試通過事件。build、vet、相依性、784 個模組內 Go 檔的格式檢查及最後 11 個頂層治理檢查通過。788 份 Go／module 來源與凍結測試指紋相符。正式來源外的兩份歷史 Go 證據保留原件，不納入格式修正。

[32 組相容性比較](compatibility-comparison.json)涵蓋四種線上模式、化學開關、間隔及梯度累積，完整公開輸出與快照在前後 487,897 bytes 逐位相同。[新程序接續](cli-continuation.json)的延遲人工範例訓練 80 步、另一程序接續 40 步，與獨立連續 120 步的模型逐位相同。小型快照只作保存恢復證據。

## 範圍與限制

- 修正本票已重現的共享狀態缺陷，未證明整個框架沒有 bug。
- 零分回饋的新損失殘差為零，既有動量、weight decay、計數及部分梯度累積仍依原有最佳化器規則處理。
- [一般測試跳過原因](full-unit-skip-reasons.json)及一般／race 摘要保存 22／23 個跳過事件，包含未提供真實資料、未啟用大型證據量測與由父測試啟用的子程序 helper。
- 本票沒有重測真實 OCR 準確率、完整圖訓練品質或生物定量正確性。受體部位仍依既有純量神經元設計整合。
- 初步完整檢查曾因診斷副本使用 `.go` 副檔名而中斷。副本保留為 `.go.txt` 後，來源檢查通過，最終完整命令重新執行，見[修正紀錄](diagnostic-source-correction.json)。中斷命令不列為通過證據。
