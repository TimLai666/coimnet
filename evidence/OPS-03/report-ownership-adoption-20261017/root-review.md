# 報告設定隔離修正審查

正式採用的七個 producer 共新增十一行切片複製，與兩份隔離候選的來源指紋相同。兩個新增公開回歸也與 Root 凍結來源相同。未新增 API、格式欄位、依賴、訓練參數或數值操作。

RunMedia、RunVideo、runRoles 的 Holdout／Seeds、RunMultiTask 的 Schedule.Tasks、多模態的 Holdout／Seeds，以及學生評估的 Seeds，均由既有 Validate 要求非空，使用 append 複製不會改變合法空值形式。Adaptive 的 FeedbackAvailable 可空，使用既有 slices.Clone 保留 nil 與非 nil 空集合。巢狀元素都是純值，不需要額外深複製。

複製放在各自原驗證之後與報告雜湊／分支之前。保留原驗證及 teacher 檢查順序。呼叫端在返回後重用設定與反向修改回傳報告的清單皆被公開回歸觀察，不增加執行期間並行修改輸入的保證。正常完整報告指紋將按一般／競態建置分開比對既有候選紀錄。

第一次完整一般測試指出兩個 INDEX 來源連結行號因新增行偏移，已核對實際格式字串後補正。這是本次修改造成的文件缺口，原失敗輸出保留，後續使用新標籤重新完整驗證，不能把首次失敗記為通過。

減法審查：沿用既有清單複製，不新增報告封裝層。兩票共用最終來源的一套驗證，不各自重跑相同全套。聲音合成另由 ticket141 處理，不在本次凍結來源混入其他修正。這些報告變更沒有模型品質改善或生物機制有效性的結論。
